## 什么是 Mnema

Mnema 是适用于任何 AI 的记忆程序。它会记住你是谁、在做什么项目、做过哪些决定，以及该怎么跟你交流，并把这些内容带入你与任何模型的对话：Claude、ChatGPT、Gemini、电脑上的内置模型、Cursor 以及各类智能体。记忆就是你电脑上的一个普通 Markdown 文件夹，不用 Mnema 也能用任何编辑器（包括 Obsidian）打开。Mnema 没有云端，也不需要账号。程序只有一个窗口（聊天、记忆、设置）和一个托盘图标（在 macOS 上位于菜单栏）。支持 Windows 10 和 11、macOS 11 及更高版本（Apple Silicon 和 Intel），以及 Linux（64 位，Ubuntu 22.04 及更高版本和类似发行版）。个人版免费且开源（AGPL-3.0 许可证），企业版另行提供。

## 记忆已开启或已关闭

记忆是 Mnema 的总开关：聊天界面左下角“记忆”面板里的开关（在“设置 → 学习 → “记忆””中也是同一个开关）。记忆关闭期间，右上角齿轮上的小圆点是黄色的。在首屏新建的记忆默认是关闭的：教程里有一步“开启记忆？”（默认选“不使用记忆”），如果没有显示教程，则会用单独的窗口问同样的问题。在开关出现之前就已有的记忆会保持开启状态。

关闭时，就是和任意 AI 的普通聊天：模型对你一无所知，Mnema 也不会记住任何内容（不进行学习，“记住”不会写入，“写入记忆”操作会被拒绝），Claude Code、Claude Desktop 和 Cursor 既无法获取记忆，也无法向其中写入。其余功能一切照常：所有模型、联席会议模式、文档及其节省 token 的功能、联网、会议、本地模型，以及对工作文件夹的文件操作（记忆文件夹对这些操作是禁止访问的）。“记忆”标签页会显示“记忆已关闭”界面，上面有“开启记忆”和“查看已记录内容”两个按钮。学习设置和“哪个 AI 能看到什么”会变灰，并标注“记忆已关闭”，附带“开启”按钮；聊天中的“不学习”按钮不可点击；状态栏显示“记忆已关闭 · 普通聊天，不会记住任何内容”。

## 记忆文件夹

记忆存放在你首次启动时选择的文件夹里。里面包含：

| 文件夹或文件 | 内容 |
|---|---|
| 00 Inbox/Inbox.md | 尚未整理的事实 |
| 10 Now.md | 今日摘要：你是谁、进行中的项目、最近的事件、14 天内的新事实、超过 30 天需要核对的状态。自动生成，不要手动修改 |
| 20 Projects/<名称>/_Project.md | 项目中心页：状态（active、paused、closed）、目标、开始日期、关键词、日志。项目文档就放在它旁边 |
| 30 People/<名称>.md | 人物卡片 |
| 60 Events/YYYY-MM.md | 按月记录的决策和状态变更，最新的在最上面 |
| 70 Memory/Profile.md | 你是谁 |
| 70 Memory/Rules.md | 如何与你协作，每行一条规则并附日期 |
| 70 Memory/Thoughts.md | 你的想法和灵感 |
| 70 Memory/Cards/<主题>.md | 主题卡片：每行一条事实，关键词和隐藏标签写在开头部分 |
| 70 Memory/Fact archive/ | 已被更新事实取代的旧事实。这些是历史记录，模型不会读取 |
| 70 Memory/Index.md | 目录：项目、卡片和人物及其关键词。自动生成 |
| 80 Meetings/ | 会议记录、转写稿和总结 |
| 90 System/Journal/<日期>.md | 日志：用通俗易懂的语言记录写入了什么、由谁写入 |
| 90 System/Recipes/ | 重复性任务的配方 |
| 95 Saves/ | 每天首次修改前的文件副本，保留最近两份 |
| 99 Archive/ | 已关闭的项目及其文档 |
| .mnema/ | 系统内部文件：AI 访问权限、修改日志、用于回滚的快照、令牌、学习设置、对话 |

记忆文件可以手动编辑。Mnema 只读取这套结构。

## 附加记忆文件夹

设置 → 程序 →“附加记忆文件夹”：除主记忆外，AI 还能一并看到的其他文件夹。任何文件夹都可以：笔记、Obsidian 库、文档、团队共享文件夹，或者另一份 Mnema 记忆。点击“连接 Obsidian”，Mnema 会自动找到你电脑上的 Obsidian 库（读取的是 Obsidian 自身的设置），并显示每个库的笔记数量：勾选的库会成为附加记忆，你也可以手动指定文件夹。其他任何文件夹，用“添加”（或“选择…”）按钮加入，旁边的“移除”按钮可以将其移除。库会先在后台完整读取一次，之后只处理有改动的笔记，所以即使有上千条笔记，也不会拖慢回答速度。Markdown 和文本文件都在你的电脑上读取，提问时只会发送相关的片段，并且总量不超过记忆本身的范围（滑块“更精准 ↔ 更省用量”）。对该 AI 隐藏的主题（#money、#health、#private 以及对应的俄语形式）也会从这些文件中剔除。Mnema 不会向这些文件夹写入任何内容，也不会从中学习。

## 事实是如何记录的

一条事实占一行，并带有日期:“- 21.09.2026 · 决定十一月启动试点”。状态会加上“(状态 DD.MM.YYYY)”的标注。同一事项的新状态会在原位置替换旧状态，旧状态进入事实归档，而这次变更会出现在事件时间线中。Mnema 自己学到的内容会标有“已学习”字样，这样你一眼就能看出哪些来自学习。

已学习事实的日期，是你说出或写下这件事的那一天，而不是 Mnema 读到它的那一天。如果 Mnema 今天读了一个月前的对话，这条事实就会带上那次对话的日期，相关决定也会归入当月的事件。这样，旧内容就不会被当成新消息。

超过 30 天的状态，Mnema 不会单独列成清单。模型知道每个状态的日期：如果对话涉及一个已超过一个月的状态，它会说明这是哪天的状态，并向你确认它是否仍然有效。

## 记忆标签页

记忆 → 画像：顶部是画像和各类事实的计数，下方是“记忆地图”——以你为中心、用气泡表示的主题：气泡大小按事实数量决定，带锁的主题表示并非所有 AI 都能看到，最近三天有更新的主题会闪动。小气泡的标签在鼠标悬停时显示。地图下方是主题卡片：“给 AI 的规则”“项目”“你身边的人”、画像的各个部分、主题卡片（最大的排在最前）以及“事件与决定”。卡片上显示事实数量和最新的两行内容（项目和人物显示前几个名字）。点击卡片或气泡，会在上层窗口中打开该主题：每条事实占一行，最新的在最上面，日期在右侧，支持搜索，点击可展开整条事实；对于学习得来的事实，还会在同一处显示“来源？”，点击铅笔图标可打开对应文件。内容相同的画像部分（例如公开和隐藏的“我是谁”）会合并显示为同一个主题。

## 画像

画像是 70 Memory/Profile.md 开头的 2–3 句话:你是谁、做什么、眼下最重要的事是什么。每个 AI 拿到的第一份内容就是它。当关于你的信息累积到至少三条事实时,Mnema 会自动生成画像,素材来自档案中公开的部分、进行中的项目,以及没有隐藏标签的卡片(与金钱、健康和私人生活相关的内容不会进入画像)。画像由你选来做学习的模型撰写;如果没有选模型,就直接把这些事实写成简短的句子。画像会在学习之后重新生成:档案有变化时立即更新;如果只是卡片和项目有变化,则每 6 小时最多更新一次。如果你自己改写了画像,Mnema 就不会再去动它。每次生成都会在日志里显示为"已生成画像",也可以在历史记录中回滚。

## 摘要 10 Now 与目录

Mnema 会在每次写入之后自动重新生成 10 Now.md 和 70 Memory/Index.md。10 Now 里有：你是谁、进行中的项目、最近发生的事、过去 14 天内的新事实（最多 12 条）以及已过时的状态。目录里列出了每个项目、卡片和人物，并附有可用来搜索它们的关键词。手动修改这两个文件没有用：下次重新生成时，你的修改就会丢失。

## Mnema 如何学习

Mnema 会在你的日常使用中自行学习，不需要填写任何问卷或表单。它会从你允许的来源中留意各种事实，然后决定是直接记下来，还是先问问你。学习在后台按定时器进行（频率取决于引擎模式：从 10 分钟到 2 小时不等），并且会在你每次于 Mnema 聊天中发送消息时立即进行。首次启动时，它会查看过去 90 天的历史记录。

首次启动时，Mnema 会问你：“允许 Mnema 查看其他程序吗？”。选择“不，仅限 Mnema”后，它只会从与它的对话以及你在对话中的修正里学习，并且只使用它自己的记忆文件夹：不会读取 Claude Code 的聊天记录、笔记、文档、Telegram、浏览器和扩展程序。选择“是，我来选择”后，会打开一个在电脑上找到的内容列表（Claude Code 聊天记录、笔记文件夹、“文档”、Telegram 导出、浏览器历史记录、扩展程序），并显示各自的路径，所有项目默认都不勾选，Mnema 只会读取你勾选的部分。邮件和日历它绝不会自行开启：这两项需要地址和密码，或者一个私密链接。

这些都可以在“设置 → 学习”中更改。“允许 Mnema 查看的内容”下有一个总开关“其他程序和浏览器”：关闭后，外部来源的卡片会被锁住，无法开启。再往下的“学习来源”中，每个来源都可以单独开启，其中一部分还可以指定路径和排除项。

Mnema 永远不会读取它自己的记忆文件夹，也不会读取它自己对模型的内部调用。

## 学习来源

| 来源 | 读取内容 |
|---|---|
| Mnema 中的对话 | 你在 Mnema 聊天中发送的消息，在你输入的同时即时读取 |
| Claude Code 中的对话 | 来自 Claude Code 历史记录（文件夹 ~/.claude/projects）中你发送的消息，仅读取新增的行。脚本发出、开头带有 "[СЛУЖЕБНОЕ-ИМЯ]" 这类标记的系统请求会被跳过 |
| ChatGPT 导出文件 | ChatGPT 数据导出中的 conversations.json 文件 |
| 你的纠正 | 你在与 AI 对话时说的“不对，不是这样”“我不是说过了吗”“绝对不要……”，会变成适用于所有 AI 的规则 |
| 笔记文件夹 | 笔记中的新增行，例如 Obsidian 库中的笔记。系统文件夹（.obsidian、.trash、.git）已被排除 |
| 邮件 | 你通过 IMAP 发送的邮件，引用内容会被截去 |
| Telegram（通过 API 的聊天记录） | 完整的聊天记录，包括你和对方的消息，仅限你选定的聊天。只读，详见“Telegram”一节 |
| Telegram（导出文件） | Telegram Desktop 导出文件中你自己发送的消息 |
| 日历 | .ics 文件或 iCal 私密链接 |
| 文档 | 所选文件夹中新增和修改过的 Word 文档、文本和笔记（.docx、.txt、.md） |
| 浏览历史 | 按天记录你读过的页面标题（Chrome、Edge、Yandex 浏览器）。默认仅观察，不做学习 |

## 学习模式

每个来源都可以单独设置学习模式:

| 模式 | 会发生什么 |
|---|---|
| 仅查看 | 只显示她……会学到什么,不会写入任何内容 |
| 全部询问 | 不会自行写入任何内容:在 Mnema 的对话中会先问你,在其他地方只显示出来 |
| 混合(默认) | 有把握的内容会自动写入。涉及个人隐私或与已有记忆相矛盾的内容,如果来自 Mnema 的对话,会直接在对话中向你确认;如果来自其他地方,则由 Mnema 自行决定。把握不大的猜测会等到再次出现时再处理 |
| 全自动 | 全部自动写入,保障措施是日志和回滚功能 |

如果同一个事实出现在多个来源中,则采用其中最谨慎的模式。

## Mnema 如何理解文本

对于日常的自然语言，Mnema 有多种解析方式（“设置” → “学习” → “用什么理解文本”）：

| 选项 | 方式 |
|---|---|
| 自动（默认） | 使用你默认对话的模型——任何已连接的模型都可以，云端的或本机的；如果一个都没有，则只识别明确的信号 |
| 不使用模型 | 只识别明确的内容：“记住……”、更正、决定（“我决定……”）、状态日期 |
| 通过订阅使用 Claude | 通过已安装的 Claude Code，不使用工具、钩子和 MCP，会话不会被保存 |
| 自己的密钥 | Anthropic 或兼容 OpenAI 的服务；密钥保存在系统的安全存储中（Windows 为 DPAPI，macOS 为“钥匙串”，Linux 为密码存储，如果有的话），而不是记忆文件夹里 |
| 本机模型 | 内置模型或 Ollama，任何内容都不会离开你的电脑 |

在把文本发送给云端模型之前，其中的敏感信息会被替换为占位标记（见“哪些内容会离开你的电脑”）。

## Mnema 如何决定:直接记下还是先问你

- 默认置信度阈值为 80%。置信度达到 80% 及以上,且该事实不属于个人隐私时,Mnema 会自动记录。置信度在 60% 到 80% 之间时,她会先问你。低于 60% 时,则等它再次出现后再判断。
- 重复出现会提高置信度:两次各 60%,合计为 84%,该事实就会被记录下来。
- 与金钱、健康、个人隐私相关的内容会进入带有 #money、#health 或 #private 标签的卡片:你可以在“哪个 AI 能看到什么”表格中对任意 AI 隐藏这些卡片。如果这类内容是在 Mnema 的对话中提到的,她会先在当场问你:“这是私人信息,要记住吗?”
- 记忆出现矛盾时(例如“住在喀山”与“来自叶卡捷琳堡”):在 Mnema 的对话中,她会当场提问(“现在是这样”“之前是对的”“两者都对”);在其他场景中,新内容会取代旧内容,如果旧的那一条包含更多信息,Mnema 会改写它,同时保留其余部分。旧的内容会进入事实归档。
- “以后不要学习这类内容”会添加一条停止短语。在历史记录中回滚已学到的记录,就表示“不要”:这条内容不会再恢复。
- 不存在“等你处理”的队列:Mnema 不会积压问题。对话下方同一时间最多只会显示一个关于记忆的问题,回答之后才会出现下一个。

## 学习动态与对话中的提问

"边用边学"动态（齿轮 → "动态"）会展示 Mnema 读了什么、理解了什么，以及为什么这样判断，例如"置信度 90%，阈值 80%，不属于个人信息——已自动记录"或"涉及金钱——已记入隐藏部分"。如果记忆需要你来确认，对话下方会出现"需要确认一下"卡片，上面有按钮；你的回答会立即被记录。每条学到的内容都有"我是怎么知道的"：来源、你说过的话、出现过多少次、为什么记录。

## 聊天与模型

Mnema 是一个可以与任意模型对话的聊天工具，所有模型一律平等。模型在聊天界面左上角选择，菜单里分为两组：

- 云端：通过互联网使用，可以用密钥（Anthropic、OpenAI、Gemini、OpenRouter、DeepSeek、YandexGPT；模型列表由 Mnema 从服务商处获取，YandexGPT 的则取自 Yandex Cloud AI Studio 的目录），也可以用订阅（Claude Code）；
- 本机：免费、无需联网，数据不会外传：内置模型（llama.cpp）、Ollama 和 Strata。

DeepSeek 使用 platform.deepseek.com 上的密钥连接。YandexGPT 使用 Yandex Cloud AI Studio 服务账号的 API 密钥（角色为 ai.languageModels.user）以及创建该账号时所在目录的 ID 来连接：连接窗口中有两个输入框。YandexGPT 的模型有：Alice AI LLM、YandexGPT Pro 5.1、YandexGPT Pro 5、Alice AI LLM Flash，以及同一目录中的 DeepSeek V4.1 Flash 和 Qwen3.6 35B。Strata 是一款独立的免费程序，用于在你自己的显卡上运行大模型（Qwen、DeepSeek）（github.com/Niko1221/Strata）：先安装它，再用 strata launch 命令启动模型——Mnema 在启动时会自动在 127.0.0.1:8080 上找到正在运行的 Strata；如果地址不同，请在 Strata 的连接窗口中填写。

这两组模型在“设置 → AI 与模型”中同样可见。回复长度上限（“设置 → 引擎”）对所有模型统一生效，包括通过订阅使用的 Claude。

记忆和你的规则会应用到每一条消息，每个模型只会拿到允许它查看的内容。每个对话都有一个 1–3 个词的名称。你可以点击名称旁的铅笔图标、双击名称，或在列表中通过对话菜单来修改它（Enter 保存，Escape 取消）。在新对话中，可以在发送第一条消息之前先设置名称，它会随这条消息一起保存。手动改过名称的对话，Mnema 之后不会再改动，同时会显示最后修改时间和消耗的 token。列表可以按日期或 token 排序，“AI”筛选器会显示与某一个模型的对话。

空白对话中的“让 Mnema 先开始”按钮：模型会先打招呼，并根据记忆建议从哪里开始。只有当事件的日期表明它确实是最近发生的，它才会称之为近期事件；超过一个月的决定，它会建议你重新核对。

## 会话

“新会话”按钮位于列表顶部，在“新对话”下方。会话是指自你上次点击以来开始的所有对话：“新对话”会在当前会话中打开一个对话，“新会话”则开始一个新的分组。在列表中，同一会话的对话由左侧的一条线连接起来，分组标题右侧显示对话数量：最上面的是“当前会话”，之前的是“会话 · 10月24日”（最后一次对话的日期）。点击标题可以折叠分组，折叠状态会被记住。点击“新会话”后不会立刻出现空行：最上面的分组仍然是“当前会话”，直到新会话中出现第一个对话。标题旁有 ⋮ 菜单：“重命名”（为分组设置自己的名称）和“删除”（删除会话及其中的对话，已置顶的对话会保留，已学习的内容仍保存在记忆中）。在出现会话功能之前开始的对话会归为一个单独的会话，排在列表末尾；已置顶的对话显示在最上方，不属于任何分组。在搜索、按 token 排序和按日期分组时，列表为普通列表，不显示会话。

按钮旁边有一个“?”：动画会演示为什么长时间停留在同一个对话里成本很高，以及新对话和新会话有什么区别。

每个对话只会向模型发送它自己的历史记录。因此，新会话中的对话从干净的上下文开始：模型会获得记忆和规则，但看不到之前对话的聊天记录。长对话每次回复都会发送越来越多的历史记录，所以开始新话题时，最好使用新对话或新会话——过去需要的内容，Mnema 已经记录到记忆中了。

当某一次回复的花费达到该对话中同一模型第一次回复的三倍时（输入 token 加上缓存和回复），回复下方会出现“对话变贵了”卡片（使用电脑本地的免费模型时不会出现）：卡片上有两条横条——第一次回复和最近一次回复——以及贵了多少倍。点击“更新记忆并开始新会话”按钮，会先一次性学习整个对话，然后以干净的上下文开始新会话。之前已经学习过的消息不会被当作重复内容。如果对话没有启用学习，该按钮只会开始一个新会话。“不再显示”会彻底关闭这条提示，想恢复可以在齿轮图标（“对话变贵提示”）中开启；卡片上的叉号只会在当前对话中隐藏它。

## 回复方式

设置 → "回复方式":名字、称呼(用"你"还是"您")、回复长度(简短、务实、详细)、性别——用于相应的措辞(Mnema 的自称用语),以及性格。所有选项都是磁贴,右侧是"回复示例":同一个关于试点项目的问题,回复会随设置即时变化,名字则在输入时就会实时更新。性格有"温和型""务实型""严谨核查型"三种,以奖章表示,核查强度从一级到三级。下方是预设方案,以及按分组划分的详细规则。

## 模型在每条消息中了解什么

回答之前，模型会拿到：
- 如何与你相处——来自"回答方式"部分的规则（性格、称呼、你自己的用词）；
- 允许这个模型查看的记忆（记忆的开头部分，以及与问题相关的内容）；
- Mnema 当前的运行情况：在哪里学习、处于什么模式、用什么来理解文本、记忆中有多少条记录；
- 今天的日期；
- 如果问题是关于 Mnema 本身，则会附上这份知识库中的相关章节。

模型以 Mnema 的身份回答，谈到自身能力时，只说 Mnema 能做到的事。它所依托的引擎的能力（例如 Claude Code 的工具）不属于 Mnema。

## 文件和文档(包括 PDF)

用输入框下方的回形针来附加文件,或者直接把文件拖进窗口。单个文件最大 25 MB。Mnema 会把文件和对话保存在一起,并在你的电脑上免费自动提取文字。

| 格式 | Mnema 的处理方式 |
|---|---|
| 带文字层的 PDF | 按页提取文字(带页码) |
| 没有文字的扫描版 PDF | 在电脑上识别文字(RapidOCR),最多 40 页,并以文本形式交给任意模型。识别所用的字符集取决于界面语言:俄语使用西里尔字母(及英文),欧洲语言使用带变音符号的拉丁字母,中文和日语使用中文与英文。如果什么都没识别出来,文件会整个交给模型:这种情况下只有通过密钥使用的 Anthropic 能读取 |
| 有密码的 PDF | Mnema 会提示文件受密码保护,并建议你去掉密码("打印 → 另存为 PDF") |
| Excel(xlsx、xls)、CSV、TSV | 按工作表提取表格,每个工作表最多 2000 行 |
| Word(docx)、PowerPoint(pptx)、OpenDocument、RTF、HTML | 提取文字;Word 中的表格按行输出,单元格之间用「 \| 」分隔 |
| 文本文件和代码(txt、md、json、xml、py 等) | 按原样提取文字 |
| 图片(png、jpg、gif、webp) | 作为图像交给模型(Anthropic、OpenAI 兼容服务商的模型,以及支持图片的 Ollama 模型可以看到图像),同时在电脑上识别图片中的文字,任何模型都能获得这些文字 |
| 其他格式 | 模型只会收到文件名 |

文档的完整文本会和对话保存在一起。除了"更精准 ↔ 更省"滑块的最精准一档,模型收到的是文档开头,以及与当前问题相关的片段,而不是整个文件。在最精准的一档,文本会被整体插入,但不超过 60 000 个字符。因此,对于 PDF,你可以:概括内容、在文中查找答案、提取各种详细信息和数字、对比两份已附加的文档、解析表格。

创建和编辑文件、生成 PDF、Word 和 Excel、修改现有的 Word 和 Excel、合并、裁剪、旋转和拆分 PDF、按路径读取文件,这些都属于文件操作(见下文相应章节)。Mnema 不会做的事:不填写 PDF 表单,不运行程序和脚本。

## 联网

输入框下方的“联网”开关只是允许搜索，并不会让每条消息都去搜索。只有在没有最新的外部数据就无法准确回答时，Mnema 才会搜索：价格、汇率、新闻、最新版本、时间表、“现在”和“今天”这类问题，以及你明确说“查一下”或“搜一下”的时候。对于关于 Mnema 本身的问题、关于你的问题、常识类问题（“什么是……”）以及针对已给文本的任务，她不会上网查询。消息里的链接始终会被读取，即使开关是关闭的。通过链接打开的网页和 VPN 订阅只能访问互联网上的地址：本机、家庭或办公室网络，以及 Mnema 的内部服务地址都会被屏蔽。

搜索免费，无需密钥：先通过 ddgs 库使用 Bing 和 Yahoo，然后直接使用 DuckDuckGo、Bing、Yandex 和维基百科。与问题中大多数关键词不匹配的结果会被丢弃。网页在你的电脑上读取并清理，模型会收到带编号的摘录，并以 [1]、[2] 的形式引用它们，来源会显示在回答下方。如果联网已关闭，而问题明显需要最新数据，Mnema 会根据已有的知识作答，并建议你开启搜索。

## 更准还是更省

设置 → 引擎 → 精细调整 → "更准 ↔ 更省" — 一个分五档的滑块，默认在中间。更准：请求中带入更多记忆，并有更多文档片段与问题进行比对，模型会更频繁地向你确认，回答也更贵。更省：带入的更少，模型只在不问不行的时候才会确认。

| 档位 | 请求中的记忆 | 文档比对范围 | 对话 | 是否确认 |
|---|---|---|---|---|
| 最省 | 2 000 字符 | 最多 3 500 | 最多 8 000 | 仅在不问不行时 |
| 较省 | 3 000 | 最多 5 000 | 最多 11 000 | 仅在不问不行时 |
| 均衡（默认） | 4 200 | 最多 7 000 | 最多 14 000 | 需要时 |
| 较准 | 8 000 | 最多 12 000 | 最多 20 000 | 更频繁 |
| 最准 | 16 000 | 全文 | 全文 | 只要有不明确之处就确认 |

除最准一档外，记忆只取开头部分，以及与问题相关的行。对话的最近 6 条消息会完整保留，更早的会被缩短到 400 字符。文档和网页则只取合适的片段。回答下方会显示节省了多少 token（估算：约 3.5 个字符对应 1 个 token）。在一份 153 000 字符的合同上实测：不做节省时输入为 29 643 个 token，启用节省后为 6 159 个，而且只有启用节省的方案给出了正确答案。

## 按钮提问、二次检查、引用

当模型需要你进一步说明时,它会用一张卡片只问一个问题:先是问题本身,再用一行说明为什么要问,下面按顺序竖排 2–4 个选项,每个选项都有一句简短的说明,告诉你选了之后会发生什么。你可以点击选项,也可以直接按键盘上的数字键来选择;卡片底部还可以用你自己的话来回答。回答之后,你选中的选项会打上勾。卡片上有一个齿轮图标,可以设置:是否用选项的形式提问、是否为选项附上说明、是否只在确有必要时才提问。"二次检查"(在设置中)会让模型在你看到草稿之前,先按照你的规则和记忆检查一遍。你可以选中回答中的一段内容,在下一条消息里引用它。回答下方的"有用"按钮,是在告诉模型哪种回答形式更适合你:被你标记的回答,模型会当作形式上的范例。

## 重复性任务

遇到第二个类似的任务时(也可以在设置中改为每次都提示,或者从不提示),Mnema 会建议你把它记成一个"配方",这样下次就不用再重新解释,也不用为了追问细节浪费 token。配方包含目标、输入数据、步骤、结果格式、检查项,以及哪些事不要做,保存在 90 System/Recipes 中。之后遇到类似的请求,Mnema 会自动按配方执行,回答下方会显示"按配方「…」执行"。判断是否"类似",是 Mnema 在你的电脑本地完成的,依据是词干是否匹配。

## 术语提示

开启“提示”后（在输入框下方的“+”菜单中），模型会在回答末尾附上一份简短的词汇表：包括难懂的术语，以及回答中出现的所有名称——人物、公司、产品、服务、社区（例如 Show HN），但你自己和你主动提到过的人除外。Mnema 会把词汇表截下来，在回答中给这些词加上下划线，鼠标悬停时就会显示对应的解释。

## 共识团

在任意回答下方点击"和不同的 AI 辩一辩"，会先弹出"和谁辩？"窗口：列出所有已连接的模型（回答的作者除外），推荐的模型已预先勾选，最多可选三位对手，由第一个被勾选的模型来做总结。回答的作者负责为自己的答案辩护，对手则负责找出它哪里不对、不完整，或者有没有更好的方案，最后给出结论：这个回答是否站得住脚，接下来该怎么做。如果只连接了一个 AI，就由它自己的不同模型互相辩论（比如 Sonnet 对 Opus）。这就是普通的共识团，只是采用辩论形式，你可以继续、停止或结束它。

输入框下方的"共识团"按钮会发起 2–4 个 AI（任何已连接的模型，包括内置模型）的讨论，轮数为 1 到 20 轮。它们轮流发言，能看到彼此的发言，并互相称呼名字，最后一位负责总结：哪些地方达成一致，哪些地方有分歧，建议怎么做。消息上方是圆桌：显示谁在发言、下一位是谁，以及"暂停"、"继续"、"结束"、"再讨论一次"按钮。"停止"（AI 回答期间的发送按钮）会立刻打断当前发言者：已说的内容会保留并标注"已打断"，其余成员等待你点击"继续"。参与成员和轮数可以在讨论过程中随时调整。每位参与者都会拿到完整的对话：最近 16 条消息完整提供，更早的消息以缩略形式提供，附带的文档按与问题的相关度摘取片段，图片中的文字、图片本身以及 PDF 也都会提供。可选格式：建议、辩论、头脑风暴、红队，以及"毒舌点评"（毫不留情地批判一个想法、简历或文本，总结以"N/10"的评分开头）。总结下方有"分享"按钮：生成一张包含结果的图片卡片。如果你在讨论过程中发言，当前发言者会停下，对话从你的消息继续；还没说过话的发言者（服务卡住了）会被立即移除。如果某位参与者的密钥不匹配或余额用完，它会说明一次，之后不再参与讨论；这时由另一位来做总结。每位参与者获取的记忆都遵循其自身的访问权限。共识团也可以接入一段正在进行的对话。

共识团窗口一开始很简洁：选择邀请谁加入讨论（2–4 个 AI，卡片上的数字是发言顺序）、讨论格式，以及按发言顺序排好所选成员的实时圆桌。点击"高级设置"可展开其余所有选项——轮数、角色、谁来总结、发言长度、事实核查和轮次计划，每一项都有各自的"?"说明。点击"简易模式"可返回简单视图。

事实核查（默认开启）：如果参与者的发言依赖某个事实、数字、日期或最新信息，它会自己上网搜索（每轮最多搜索两次），并附上 [1]、[2] 这样的链接来回答。来源会显示在它的发言下方。对于观点和建议，它不会搜索。带搜索的回合会更长：模型会回答两次，一次在搜索前，一次在搜索后。可以在高级设置中通过"联网搜索"关闭。

"共识团"按钮上的齿轮图标会打开同样的设置：

| 设置项 | 选项 |
|---|---|
| 格式 | 建议：先给出自己的回答 → 核查 → 改进 → 争议点 → 共同答案。辩论：参与者隔一位分为正方和反方，立场 → 反驳 → 裁决。头脑风暴：不加批评地提出想法 → 在他人想法上延伸 → 三个最佳想法（为什么、第一步、风险）。红队：攻击你的计划 → 如何补上漏洞 → 风险清单及应对措施 |
| 角色 | 为每位参与者设置：无角色、怀疑者、实干家、财务专家、法律专家、创意人、分析师、客户 |
| 总结者 | 按顺序的最后一位，或指定的某位参与者：在最后一轮中由他最后发言 |
| 发言长度 | 简短（最多 80 字，总结最多 120 字）、适中（150 和 180 字）、详细（300 和 350 字） |

窗口底部是示意图：按发言顺序排列的参与者圆桌、辩论中的立场方、总结者旁的奖杯，以及所选格式的轮次计划。格式、长度和角色会被记住，下次召开共识团时自动沿用。

## 文件操作

聊天中的模型可以处理文件：读取文件（包括 PDF、Word、Excel、PowerPoint；扫描件和图片会在你的电脑上完成识别）、查看文件夹、按关键词查找文件、创建或重写文本文件（.md、.txt、.csv、.json、.html）、修改文件中的某一段、把带有标题、列表和表格的文本生成 PDF、Word 或 Excel 文档，以及向记忆中写入一行内容。任何模型都可以使用，无论是云端模型还是本地模型。

现成的文档：

| 内容 | 方式 |
|---|---|
| Word (.docx) | 替换文本并保留格式：即使短语中含有加粗的词，或在文件内部被拆成了多段，也能找到；新文本沿用旧短语起始位置的格式。页眉页脚和脚注同样适用 |
| Excel (.xlsx, .xlsm) | 单元格中的值和公式（"Лист1!B3 = 1500"、"C7 = =SUM(C1:C6)"），以及单元格中的文本替换；其他工作表、格式和公式保持不变。包含图表、图片或数据透视表的工作簿，Mnema 不会修改——因为保存时它们会丢失 |
| PDF | 合并多个文件，按需要的顺序保留指定页面（同样可以裁剪、删除、调整顺序），将页面旋转 90、180 或 270 度，拆分成多个部分。源文件不会被改动，新文件也不会覆盖已有文件 |

默认情况下，Mnema 会直接执行操作。如果在"设置" → "程序" → "文件操作"中开启"每次操作前都征求我的许可"，回复下方就会出现"Mnema 想要"卡片，说明具体要对哪个文件做什么，并提供"是"、"本次对话中都允许"（本次对话中同类操作不再询问）和"否"按钮。操作完成后，对话中会留下一行"已创建文件 …"，并带有"在文件夹中显示"按钮，模型随后继续回答。不会运行任何程序，也不会向互联网发送任何内容。

允许操作的范围：记忆文件夹，以及你在"设置" → "程序" → "文件操作"中添加的工作文件夹；也是在这里可以整体关闭文件操作。系统文件夹 .mnema 不可访问。模型读取记忆中的笔记时遵循它自己的权限：被隐藏的主题仍然保持隐藏。文档绝不会覆盖已有文件——新文件会被命名为"отчёт (2).pdf"。任何写入都可以撤销："记忆" → "历史"——记忆文件夹和工作文件夹都适用。PDF 通过 Edge、Chrome 或 Chromium 浏览器在不显示窗口的情况下生成：每台 Windows 10 和 11 电脑都自带 Edge，在 macOS 和 Linux 上则需要安装其中之一。

## 不学习模式的对话

输入框下方的“不学习”开关：打开后，从第一条消息起，这次对话就不会让记忆学到任何东西。模型仍然可以看到记忆，但对话中的新内容不会被写入，在这次对话里点“有用”标记也不会产生任何学习效果。

## 语音与会议

输入框下方的麦克风按钮：可以用来说出指令，也可以用来录制会议。指令会通过麦克风录下来，在电脑上完成识别，然后作为消息发送出去，音频随即删除。会议录制会同时录下麦克风和电脑的声音，分成两个声道，所以在转写文本里能看出是谁在说话。你也可以直接把音频或视频拖进聊天窗口（包括 iPhone 的 .mov，以及 .mp4、.avi、.3gp、.m4v）。如果还没有识别模型，需要先下载一次（约 0.5 GB，需要联网），Mnema 会提示你。识别使用的是在电脑上运行的 faster-whisper（如果已下载，会用 small 或 medium 模型）。也可以通过 OpenAI 密钥使用云端 Whisper：费用为每分钟 $0.006，每小时约 $0.36。"自动决定"模式（默认）会在第一分钟测一下电脑的速度，如果在会议时长或 10 分钟内处理不完，就会询问你是否改用云端。音频和 Расшифровка.md 会保留在 80 Meetings 中，转写文本和简短总结会发到聊天里，你说的话会用于学习。会议录制窗口右上角有"设置"按钮，点击后进入"设置 → 会议录制"。在那里，会议的流程被画成四个步骤：录制（是否保存音频）、转写（在哪里转写、精度如何）、总结（由哪个模型来总结）、记忆（从你说的话中学习）。点击某个步骤，下方会显示它的说明和相关设置。顶部有现成的预设："隐私"（全部在电脑上处理，音频会被删除）、"均衡"（自动决定）、"快速"（云端 Whisper）。总结所用的模型也可以直接在录制窗口里选择。

## 电脑本地内置模型

Mnema 内置了 llama.cpp 服务。你可以从 Hugging Face 上的 13 个 GGUF 模型中任选,分为五组:轻量型(Gemma 3 1B、Qwen2.5 1.5B、Llama 3.2 3B)、均衡型(Gemma 3 4B——推荐、Qwen3 4B、Phi-4 mini)、高智能型(Qwen2.5 7B、Llama 3.1 8B、YandexGPT 5 Lite 8B)、特殊型(Qwen3 4B Thinking、Qwen2.5 Coder 7B)、大型(Gemma 3 12B、Mistral Small 3.2 24B)。每个模型都会标明用途、大小、所需内存,以及按你当前网络速度估算的下载时间。下载支持暂停和断点续传。模型存放在 ~/.mnema/models。本地模型无需联网,也完全免费,但能力不如云端模型。

选用本地模型期间,聊天窗口顶部会显示一个"温度计":包括 CPU 负载、模型占用比例、内存,以及温度(前提是系统能提供温度数据:Windows 不一定支持,Linux 通常支持,macOS 不支持)。如果模型持续一分钟让电脑发热,Mnema 会自动降低它的优先级,并告诉你。界面上还有"降低负载"和"停止模型"两个按钮。

## 引擎：Token 与负载

进入“设置 → 引擎”，共有三种模式：

| 模式 | 更精准 ↔ 更省 | 回复长度 | 内核数 | 上下文 | 学习 |
|---|---|---|---|---|---|
| 节能 | 更省（3 000 字符记忆） | 最多 1 000 个 token | 四分之一 | 4 096 | 每 2 小时一次 |
| 平衡（默认） | 平衡（4 200） | 3 000 | 一半 | 8 192 | 每 30 分钟一次 |
| 最大 | 最精准（16 000，不做压缩） | 8 000 | 除一个以外的全部 | 16 384 | 每 10 分钟一次 |

精细调节只有一栏：“更精准 ↔ 更省”、最长回复、每月额度、处理器内核数、记住的上下文量。只要手动拖动任何一个滑块，模式就会切换为“自定义”。月度额度统计的是云端 token；用完后，云端请求会停止并给出清晰的提示，而本机上的模型仍可继续运行。通过订阅使用 Claude 时，无法限制其回复长度。

下方还有一个单独的“后台”板块：“不打扰工作”会降低本机模型的优先级，“后台学习”用来设置 Mnema 检查学习来源的频率。

## 谁能看到什么

“设置 → 安全 → “哪个 AI 能看到什么””——一张表格：各个 AI 按列排列，记忆的各个部分按行排列，另有一个“已屏蔽主题”区块（金钱、健康、个人——即使在允许访问的部分中，这些内容也会被剔除）。点击后立即保存，列下方的开关可以完全关闭对应的 AI。默认情况下不隐藏任何内容，任何 AI 都可以把新内容放进收件箱：

| AI | 可查看 | 可追加写入 |
|---|---|---|
| 本地模型（内置模型、Ollama、Strata） | 全部 | 收件箱 |
| Claude、Claude Code | 全部 | 收件箱、决策、项目、卡片、人物、规则 |
| ChatGPT | 个人资料、规则、项目、卡片、决策 | 收件箱 |
| OpenRouter、DeepSeek、YandexGPT | 个人资料、规则、项目、卡片、决策 | 收件箱 |
| Gemini | 个人资料、规则、卡片 | 收件箱 |
| Cursor | 规则、项目 | 收件箱 |

本地模型可以看到全部内容，因为本地不会向外发送任何数据。金钱、健康和个人这几个主题，默认对所有已开放“卡片”的 AI 可见：想对某个 AI 隐藏某个主题，就在它那一列点击“可见”，状态会变成“已隐藏”。

标题上的隐藏标签（例如“## 金钱 #money”）会隐藏该标题及其下的所有内容。写在名称上的标签“# 金钱 #money”，或写在文件属性（tags）中的标签，会隐藏整个文件。中文标签同样有效——#деньги、#здоровье、#личное——不区分大小写，也支持 Obsidian 写法的属性（以列表形式书写的 tags）。在已隐藏的卡片中更改状态时，该事件会带着相同的标签进入事件流，因此同样会被隐藏。

## 哪些数据会离开你的电脑

在向云端 AI(聊天、顾问团、二次校对、对话命名、学习大脑、画像)发出任何请求之前,以及在向搜索引擎发出请求之前,银行卡号(经 Luhn 校验)、密码、PIN 码和 CVV、API 密钥、VPN 的令牌和密钥、手机号、护照、SNILS、INN 以及账户号码都会被替换为 [ТЕЛЕФОН-1] 这样的标记。返回的回答会在你的电脑上还原为真实内容。可在“设置 → 安全”中开启。使用第三方云端的学习大脑获得记忆的规则与聊天中的这个 AI 相同:被隐藏的主题不会发送给它。每一次对外请求都会在日志中记录为一行:时间、发送给谁、用途(聊天回答、学习、画像、对话命名、联网搜索)、字符数、可用记忆中发出了多少,以及隐藏了什么(只显示数量,不显示具体内容)。未发出的请求(没有程序、没有密钥、没有网络连接)不会写入日志。“记忆”卡片左下角的“本周外发”会显示最近 7 天的报告。

## 用密码加密记忆

设置 → 安全 → "用密码加密记忆",支持 Windows、macOS 和 Linux。首次启动时也会通过"要用密码保护记忆吗?"这一步提供同样的选项:默认不设密码,你可以输入自己的密码,也可以点击"生成强密码"。对于已加密的记忆,与 Google Drive、Dropbox、自己的文件夹或工作站同步时只会发送加密后的文件;使用不同密码的副本不会被接受,也不会覆盖你的记忆。Mnema 会自动加密笔记,以及记录你说过什么、做过什么的内部文件:对话、附件文本、日志及其用于回滚的快照、学习痕迹、数据外发报告、画像。没有密码,即使复制了整个文件夹也无法读取这些内容。

| | |
|---|---|
| 原理 | 随机生成的记忆密钥(AES-256-GCM)用来加密文件,密码则通过 scrypt 加密这个密钥;两者都存放在 .mnema/crypto.json 中 |
| 密码 | 不少于 8 个字符,无法找回:忘记密码就再也无法恢复记忆。可以随时更换密码,更换时不会重写文件 |
| 在这台电脑上记住 | 密钥保存在系统的安全存储中(Windows 使用 DPAPI,macOS 使用"钥匙串",Linux 使用系统密码库;如果没有,则保存为主目录中仅你本人可访问的文件):Mnema 打开时不会再询问密码。关闭此选项后,每次启动都会询问密码,在输入之前 Mnema 不会显示任何内容,也不会进行学习 |
| 不加密的内容 | 二进制文件(PDF、Word、图片、会议录音),因为需要由其他程序打开;密码验证之前就需要用到的设置(语言、模型、AI 访问权限);其他程序的文件夹(.obsidian 等) |
| 代价 | Obsidian 和其他编辑器无法打开加密后的笔记。如果其他程序在文件夹中写入了笔记,Mnema 会在下次打开时将其加密 |
| 中途中断 | 文件是逐个加密的:先在旁边写入新文件,确认能够原样读回,然后才替换旧文件。如果中途关机,部分文件会保持未加密状态,但都可以正常读取,下次打开时 Mnema 会继续加密剩余的文件 |
| Claude Code、Cursor(MCP) | 照常获取记忆,前提是 Mnema 正在运行,或者密码已在这台电脑上被记住 |

"取消加密"(同一个开关,需要输入密码)可恢复为普通文件。

在 Windows 上还可以使用系统自带的加密(EFS):对你、Mnema 和其他程序都是透明的,密钥就是你的 Windows 账户,Windows 家庭版不支持。

## 历史与回滚

每一条写入记忆的内容都会进入日志：谁写的、写了什么、什么时候写的。打开"记忆" → "历史"：任何改动都可以一键回滚。如果文件之后又被修改过，回滚只会移除这条记录对应的那几行，保留之后的修改；只有当这一行本身已经被手动改过时，才会拒绝回滚。每天第一次修改某个文件之前，Mnema 会先在 95 Saves 里存一份副本，保留最近两份。来自聊天、学习和其他 AI 的写入会逐条依次处理，所以同时写入时不会互相覆盖丢失。如果你在 Mnema 编辑器里编辑文件期间，该文件已被改动，Mnema 不会覆盖它，而是会提示你重新打开。

如果同一条规则被换了说法（比如"总结对话时简短一点"和"让总结保持简短"），Mnema 不会再添加第二行，而是用新的说法改写原来那一行。

## 连接其他 AI

- Claude Code、Claude Desktop、Cursor：设置 → "AI 与模型" → "其他 AI 中的记忆" → 点击卡片上的"连接"。通过 MCP 连接：memory_context、memory_search、memory_remember、memory_stale、memory_journal、memory_undo。上下文会被拆分为每段最多 9 000 个字符。Cursor 只会获取规则和项目，不会写入任何内容。卡片上可以看到是否已经连接。
- ChatGPT 和 Gemini：在 Mnema 的聊天中使用你自己的密钥（设置 → "AI 与模型" → OpenAI 或 Gemini 卡片 → "填写密钥"）。没有浏览器扩展：凡是 AI 自己做不到的事，Mnema 都在你的电脑上完成。
- 通过 MCP，每个 AI 在日志中只能看到允许它读取的内容的记录，也只能撤销自己写入的记录。从便携版更新后，Claude 和 Cursor 中的连接会自动切换到新版程序。
- 模型：设置 → "AI 与模型"。最上方是"当前回答者"：默认模型的徽章及其选择。下面是"模型"，分为两个部分："付费"（"订阅"子部分——Claude 订阅；"API 密钥"子部分——ChatGPT、Claude · API 密钥、DeepSeek、Gemini、OpenRouter、YandexGPT，按用量计费，与订阅分开）和"免费"（内置模型、Ollama 和 Strata，运行在这台电脑上）。左上角的模型菜单以及首次启动时的"和哪个 AI 对话？"步骤也是这样划分的。卡片是以各提供商品牌色呈现的同等徽章：内置模型、Claude 订阅、Claude · API 密钥（Anthropic）、ChatGPT（OpenAI API 密钥）、Gemini、OpenRouter、Ollama。ChatGPT 和 Gemini 只能通过 API 密钥连接：ChatGPT Plus 和 Gemini Advanced 订阅不提供密钥，API 需要分别在 OpenAI 和 Google 单独付费，按用量计费。已连接的卡片是彩色的，状态为"已连接"，未连接的是灰色的。卡片上只有一个按钮："填写密钥" → 密钥输入框直接在卡片中展开 → "保存并查找模型"或"取消"；Ollama 填写的是地址，内置模型则是"选择并下载"。如果电脑上装有 Claude Code，Claude 订阅会自动出现：Mnema 不仅会在程序搜索路径中查找它，还会在各类安装程序放置它的位置（官方安装程序、npm、WinGet、Volta、bun、Homebrew）以及 Claude Desktop 应用内部查找。如果找到了 Claude Code 但尚未登录账号，卡片上会显示"登录"按钮：会打开 Claude Code 窗口，在那里用订阅登录，然后点击"重新检查"。如果没有找到，则显示"安装方法"。每个已连接的 AI 都有"关闭"按钮：它会从所有模型列表中消失（聊天、联合会诊、"有记忆与无记忆"），密钥和设置会保留，点击"开启"即可恢复。如果某个 AI 已连接但因账号原因无法响应——Claude 的额度或订阅用完、账户余额不足、Claude Code 的登录已过期、密钥未被接受——卡片会显示"无法使用"和原因，该 AI 会从列表中移除，由下一个可用的 AI 来回答。"重新检查"按钮会发送一个小的真实请求。左上角的模型菜单对所有 AI 的结构都一样：每个已连接的 AI 显示三个最佳模型（最新的完整版，然后是轻量的 mini 和 flash），以及带计数的"全部模型"链接。在"全部模型"中，先是可用的模型，分隔线下方是"旧版与辅助"：往代模型（gpt-3.5、gpt-4、Claude 3）、带日期的副本，以及用于图片、语音和搜索的模型。即使所选模型不在三个最佳模型之中，也会显示在菜单里。密钥和检查功能收在列表下方。额度用完后，Mnema 会在半小时后自动重试。密钥在保存时会立即验证：无效的密钥不会被视为已连接。在"其他 AI 中的记忆"里，已连接的卡片上会沿着 Mnema → 程序的连线有一个圆点在移动。
- 内置模型：设置 → "AI 与模型" → "本地模型"。

## 代理与 VPN

所有访问互联网的流量(模型、搜索、下载模型)都会走同一个代理:优先使用你在 Mnema 里设置的代理(首次启动时、托盘菜单中的“代理…”,或“设置”→“程序”→“VPN 和代理”),其次是系统代理(Windows;macOS 在“系统设置”→“网络”;Linux 读取 https_proxy 环境变量和 GNOME 的设置),都没有就直接连接。支持带用户名和密码的 HTTP 和 SOCKS5 代理,密码保存在系统的安全存储中。也支持通过密钥使用 VPN:粘贴 vless://、vmess://、trojan://、ss:// 链接或 https:// 订阅地址,Mnema 就会启动 Xray,且只供自己使用(可选“导入密钥”从剪贴板读取,或“手动输入密钥”)。你也可以改用已经在运行的 VPN 客户端。“检查”会通过代理尝试连接 Anthropic,并告诉你哪里出了问题。内置模型不会走代理。

## 窗口、托盘与安装

首次启动时会有一个简短的介绍:六个使用场景,每屏只讲一个要点(不用反复解释、所有 AI 共用一份记忆、任何 AI 都更省 token、会议 → 任务、记得决定和截止日期、机密留在你手里),然后选择 AI。关于 token 的场景展示了"节省 token"一节中的实测:针对一份 153 000 字符合同的提问,把全文发给 AI 要 29 643 个输入 token,使用 Mnema 只需 6 159 个。点击"跳过"可立即关闭介绍。

关闭窗口会将其隐藏到托盘,学习会继续进行;第一次关闭时,Mnema 会询问"最小化到托盘还是退出",并记住你的选择。托盘菜单中的"退出"会停止一切运行。托盘菜单包含:"打开 Mnema"、"立即学习"、"暂停学习"、"代理…"以及开机自启动项(Windows 上为"随 Windows 启动",macOS 上为"登录 macOS 时打开",Linux 上为"登录系统时启动")。重复启动不会打开第二个实例,而是显示已运行的那个窗口。在 Windows 上,Mnema 启动时会自动清除托盘中已被结束进程遗留的图标。如果 Linux 桌面不显示托盘,关闭窗口就会直接退出程序。

安装程序无需管理员权限,会把 Mnema 安装到 %LOCALAPPDATA%\Programs\Mnema,并检测旧版本,只删除旧版本的程序文件:该文件夹中的其他内容(例如创建在程序旁边的记忆)都会保留。卸载程序同样不会删除记忆。也提供压缩包形式的便携版。安装程序目前还没有数字签名:Windows 会显示"Windows 已保护你的电脑",点击"更多信息" → "仍要运行"即可。在全新的 Windows 10 上,Mnema 会自动安装 Microsoft WebView2 窗口组件(只需联网一次)。macOS:提供 .dmg 镜像,把 Mnema 拖到"应用程序"中即可。程序没有 Apple 签名,所以第一次请右键点击它 → "打开"(或者前往"系统设置" → "隐私与安全性" → "仍要打开")。Linux:提供单个 .AppImage 文件(赋予可执行权限后运行)或带文件夹的 .tar.gz 压缩包。Linux 上的窗口由 Qt 绘制;如果打不开,需要安装 libxcb-cursor0 和 libfuse2(AppImage 需要后者)。

如果启动时找不到记忆文件夹(被移动、重命名,或外接硬盘没有连接),Mnema 会如实告知,并让你选择:指定它现在的位置、重新检查,或新建一份记忆。最初的几个界面会使用系统语言。服务出错时,Mnema 会用通俗的话说明:发生了什么、该怎么办;错误会保留在对话中,被中断的回复会加上标记,点击"停止"会立即释放该对话。

## 齿轮、主题、语言、成就

右上角的齿轮：学习（最上面显示状态；开启记忆时，同一处有学习暂停开关，关闭记忆时只显示"记忆已关闭"字样；模式、动态）、主题、语言、成就（可以关闭）、"Mnema 是如何运作的"（导览）、"记忆是如何工作的"（指南）和"Mnema 手册"。已关闭的提示也可以在这里重新打开："新对话中的教程"和"关于高成本对话的提醒"。任何窗口的关闭按钮都是一个透明圆圈，里面有一个细细的叉号，大小与"?"图标相同，按 Escape 键也可以关闭。在不学习的对话中，齿轮上的圆点是橙色的；在其他情况下，圆点则按学习状态显示。齿轮上的圆点表示当前状态：绿色表示正在学习，黄色表示记忆已关闭或学习已暂停，灰色表示只学习明确的内容或已关闭。学习状态也会显示在输入栏里："Mnema 正在学习 · 记忆已于 N 分钟前更新"。如果没有可用于解析语音的模型，那里会显示"Mnema 只记住你明确说出的内容"：只会记录明确的内容（"记住……"、更正、决定）。

界面支持九种语言：俄语、英语、中文、西班牙语、印地语、葡萄牙语、法语、德语、日语。模型会用你所选的语言回答。对话和记忆不会被翻译。

成就：共有 99 个奖励，分为五组（上手、记忆成长、节省与习惯、隐私、稀有），大多数稀有成就在获得之前都是隐藏的。奖励经验值（10、25、50、100）可以提升等级，从"新手"一直到"永恒记忆"。


齿轮菜单里有"Mnema 手册"，这就是程序内置的手册：左侧是各个章节，上方是搜索栏，搜到的内容会高亮显示。设置总是从第一个部分"AI 与模型"打开。启动时，Mnema 会短暂显示一秒钟的启动画面：logo、名称和标语"Free Memory AI Interface"。输入栏的齿轮很小，位于右上角"?"的旁边，点击可打开输入栏设置。

## 多个记忆库

在“设置”中，左侧各分区下方有一个“记忆”板块：这里列出了这台电脑上的所有记忆库，当前打开的那个会打上勾。点一下其他记忆库，就会切换到它。点“新建记忆库”会进入首屏，当前的记忆库仍保留在列表中。记忆库右侧的 ⋮ 菜单里有“重命名”和“删除”：“重命名”修改的是列表中显示的名称（磁盘上的文件夹名保持不变）。删除会让你确认两次：第二个窗口“确定要删除……吗？”里会列出将被清除的内容（画像、事实、对话、历史记录），而“删除”按钮要等 10 秒后才会启用——按钮下方有一条红色进度条逐渐变短，并显示倒计时。文件夹会被移入回收站，你可以从那里恢复。如果删除的是当前打开的记忆库，Mnema 会先将其关闭，然后切换到列表中的下一个；如果没有其他记忆库，则回到首屏。

## Telegram

"设置 → 学习 → "Telegram"。Mnema 通过 Telegram 的 API 读取 Telegram，并且只读：Mnema 内置的 Telegram 客户端只能登录和读取，其他任何操作（发送、删除、标记为已读、加入、回应）都会在程序内部被拦截，根本不会发出。登录方式和 Telegram Desktop 一样：需要来自 my.telegram.org（API development tools）的 api_id 和 api_hash、手机号、Telegram 发来的验证码，以及云密码（如果你设置了的话）。下方是"要读取的聊天"：点击"添加聊天"会打开你的私聊和群组列表，支持搜索，勾选需要的即可。在没有选择任何聊天之前，Mnema 不会读取任何内容。频道和机器人无法选择。在选中的聊天里，Mnema 会读取完整的对话：你的发言标记为"我"，其他人则标记为对方的名字，这样 Mnema 既能了解你，也能了解你身边的人。登录信息会加密保存在系统的安全存储中，聊天列表和学到的内容保存在记忆文件夹里，Mnema 没有自己的服务器。"断开连接"会清除登录信息；而在 Telegram 里，这个会话会一直保留在"设备"中，直到你在那里手动将其终止。

## 左下角的"记忆"卡片

卡片有两行，每一行都能直接给你看证据："电脑本地记忆"会打开记忆文件夹，"访问设置"会打开"哪个 AI 能看到什么"表格。卡片上的齿轮通向防护设置，旁边的绿色"?"会打开"记忆是如何工作的"指南，共 12 章：左边是目录，右边依次是场景、讲解、示例（你说了什么、记忆里发生了什么）和"试一试"按钮，点它会跳到程序里真实的对应位置。章节依次是：电脑上的文件夹、记忆文件夹的结构、事实的日期——你说这句话的时间、从对话中学习、直接记下还是先问你（60% 和 80% 两个阈值）、纠正会变成规则、回答前先挑出需要的内容、AI 的权限、机密信息、过时内容会再确认、带回滚的历史记录、电脑上的模型。最后是"自己验证"：文件夹、谁能看到什么、哪些内容发送到了外部。

试一试（输入框下方的"+"菜单和"记忆"页面）：
- "初次见面"——七个简短的问题：你是谁、住在哪里、眼下最重要的事、项目、身边的人、希望 AI 怎样和你说话，以及 AI 绝对不能做什么。你的回答会作为普通事实存入记忆，不会覆盖任何已有内容。
- "Mnema 有多了解你"——由十条记忆事实组成的测验："正确"（该事实的状态会更新为今天的日期）、"已经不是了"（你写下现在的情况，旧内容进入事实归档）、"不对"（该事实进入归档）。最后会给出得分。
- "有记忆 vs 无记忆"——向已连接的 AI（最多三个）提一个问题，每个 AI 回答两次：一次像普通的无记忆聊天，一次通过 Mnema。两种回答并排显示。
- "烤问"——以"烤问"形式进行的多模型会商。

任何结果都可以做成图片卡片（"分享"）：复制、保存到"图片/Mnema"，或者复制带链接的现成帖子文案。图片上只包含发送前窗口中能看到的内容。

## Mnema 的局限

- 不会运行程序和脚本。对文件只能执行"操作":仅限记忆文件夹和工作文件夹,每一步都记录在日志中,并且可以回滚。
- 系统级加密(EFS)仅支持 Windows;使用 Mnema 密码加密则在所有系统上都可用。
- 对于较长的扫描件,只识别前 40 页。
- 没有网络时,云端模型和搜索无法使用。如果对话进行到一半网络中断,会改由电脑上的本地模型来回答(前提是你已下载该模型),并在回答上方用一行文字提示。
- 在你提供地址和密码或链接之前,不会读取邮件和日历。
