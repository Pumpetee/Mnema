## Mnemai とは

Mnemai は、あらゆる AI のためのメモリープログラムです。あなたが誰なのか、何に取り組んでいるのか、どんな決定をしたのか、どう話しかけてほしいのかを覚えていて、それをどのモデルとの会話にも差し込みます。対応しているのは Claude、ChatGPT、Gemini、パソコン内蔵のモデル、Cursor、そしてエージェントです。メモリーは、あなたのパソコン上にある普通の Markdown ファイルのフォルダーです。Mnemai がなくても、どんなエディター(Obsidian も含む)でも開けます。Mnemai にはクラウドもアカウントもありません。プログラムは、ひとつのウィンドウ(チャット、メモリー、設定)と、トレイのアイコン(macOS ではメニューバー)で構成されています。対応環境は Windows 10 と 11、macOS 11 以降(Apple Silicon と Intel)、Linux(64 ビット、Ubuntu 22.04 以降とその系統のディストリビューション)です。個人版は無料のオープンソース(ライセンスは AGPL-3.0)で、企業向けの版は別に用意されています。

## メモリのオン/オフ

メモリは Mnemai の一番大もとのスイッチだよ。チャット画面の左下にある「メモリ」パネルのスイッチで切り替えられる(「設定 → 学習 → 「メモリ」」にある同じスイッチでも OK)。メモリがオフのあいだは、右上の歯車アイコンの点が黄色になる。最初の画面で新しく作ったメモリは、オフの状態から始まる。チュートリアルには「メモリを有効にする?」というステップがあって(デフォルトは「メモリなし」)、チュートリアルが表示されなかった場合は、同じ質問が別のウィンドウで表示される。スイッチが登場する前から使っていたメモリは、そのままオンのままだよ。

オフのときは、どの AI とも普通のチャットをしている状態になる。モデルはユーザーのことを何も知らないし、Mnemai も何も記憶しない(学習は行われず、「覚えて」と言っても書き込まれず、「メモリに書き込む」アクションは拒否される)。Claude Code、Claude Desktop、Cursor もメモリを受け取れないし、メモリに書き込むこともできない。それ以外はすべて今までどおり使える。どのモデルでも、コンソーシアムも、ドキュメントとそれによるトークン節約も、インターネットも、ミーティングも、ローカルモデルも、作業フォルダ内のファイル操作も使える(ただしアクションからはメモリフォルダにアクセスできない)。「メモリ」タブには「メモリはオフです」という画面が表示され、「メモリを有効にする」と「記録済みの内容を見る」のボタンが並ぶ。学習の設定と「どの AI に何を見せるか」は薄く表示されて、「メモリはオフです」という注記と「有効にする」ボタンが付く。チャットの「学習なし」ボタンは押せなくなり、ステータスバーには「メモリはオフ · 通常のチャット、何も記憶されません」と表示される。

## メモリフォルダ

メモリは、最初の起動時に選んだフォルダに保存されているよ。中身はこうなっている:

| フォルダ / ファイル | 内容 |
|---|---|
| 00 Inbox/Inbox.md | 未整理の事実 |
| 10 Now.md | 今日のまとめ。あなたが誰か、進行中のプロジェクト、最近の出来事、14日以内の新しい事実、30日より前のステータスで確認が必要なものが入る。自動で作られるので、手で編集しないでね |
| 20 Projects/<名前>/_Project.md | プロジェクトのハブ。ステータス(active、paused、closed)、目標、開始日、キーワード、ログが入る。プロジェクトのドキュメントは同じ場所に置かれる |
| 30 People/<名前>.md | 人物カード |
| 60 Events/YYYY-MM.md | 決定事項やステータスの変更を月ごとにまとめたもの。新しいものが上に来る |
| 70 Memory/Profile.md | あなたが誰か |
| 70 Memory/Rules.md | あなたとどう接するか。1行につき1つのルールと日付 |
| 70 Memory/Thoughts.md | あなたの考えやアイデア |
| 70 Memory/Cards/<トピック>.md | トピックカード。1行に1つの事実を書き、キーワードと非表示タグはヘッダーに入る |
| 70 Memory/Fact archive/ | より新しい事実に置き換えられた事実。履歴として残るだけで、モデルには渡されない |
| 70 Memory/Index.md | 目次。プロジェクト、カード、人物をキーワード付きで一覧にする。自動で作られる |
| 80 Meetings/ | 会議の記録、文字起こし、まとめ |
| 90 System/Journal/<日付>.md | ジャーナル。何がいつ誰によって記録されたかを、人にわかる言葉で残す |
| 90 System/Recipes/ | 繰り返し作業のレシピ |
| 95 Saves/ | その日の最初の編集の前に取るファイルのコピー。直近の2つが保存される |
| 99 Archive/ | 完了したプロジェクトをドキュメントごと保管する |
| .mnema/ | 内部用。AIのアクセス権、編集ログ、ロールバック用のスナップショット、トークン、学習の設定、会話が入る |

メモリのファイルは手で編集してもいいよ。Mnemaiが読むのは、この構造だけだよ。

## 追加のメモリフォルダ

「設定」→「アプリ」→「追加のメモリフォルダ」: メインのメモリと一緒にAIが参照できる、ほかのフォルダです。メモ、Obsidianのボールト、ドキュメント、チームの共有フォルダ、もうひとつのMnemaiのメモリなど、どんなフォルダでも使えます。「Obsidianを接続」ボタンを押すと、パソコン内のObsidianのボールトをObsidian自身の設定から自動で探し、ノート数つきで一覧表示します。チェックを入れたボールトが追加のメモリになります。フォルダを手動で指定することもできます。Obsidian以外のフォルダは「追加」(または「選択…」)ボタンで加えられ、横の「削除」で外せます。ボールトは最初に一度だけバックグラウンドですべて読み込まれ、その後は変更されたノートだけを読み込むので、ノートが数千件あっても回答が遅くなることはありません。Markdownとテキストファイルはパソコン上で読み込まれ、質問と一緒に送られるのは関係のある部分だけです。送る量はメモリと同じ範囲内に収まります(スライダー「正確さ ↔ 節約」)。このAIに対して非表示にしているトピック(#money、#health、#private、およびそのロシア語表記)は、これらのファイルからも取り除かれます。Mnemaiがこれらのフォルダに書き込むことはなく、これらのフォルダから学習することもありません。

## 事実の記録のされ方

1つの事実は、日付つきの1行で記録されるよ。例: "- 21.09.2026 · Решили запускать пилот в ноябре"。ステータスには "(статус ДД.ММ.ГГГГ)" という注記がつく。同じ対象の新しいステータスは古いものをその場で置き換え、古いほうは事実のアーカイブへ移され、変更はイベントのタイムラインに残る。Mnemai自身が学習した内容には「学習済み」という印がつくので、学習から得られたものだとひと目でわかる。

学習した事実の日付は、あなたがそれを話した、または書いた日であって、Mnemaiがそれを読んだ日ではない。たとえばMnemaiが今日、1か月前のやり取りを読み込んだ場合、その事実にはそのやり取りの日付がつき、決定事項もその月のイベントに入る。だから、古い話が新しい出来事として扱われることはない。

30日より古いステータスを、Mnemaiが別のリストにまとめて表示することはない。モデルは各ステータスの日付を把握しているので、会話が1か月以上前のステータスに関わるときは、それがいつの時点のものかを伝えたうえで、今も有効かどうかを確認してくれる。

## 「メモリ」タブ

メモリ → ポートレート: 一番上にファクト数のカウンターつきのポートレートがあり、その下に「メモリマップ」があります。あなたを中心に、トピックがバブルで周りに並びます。バブルの大きさはファクトの数に比例し、一部のAIにしか見えないトピックには鍵のマークが付き、直近3日間に更新されたものはふわっと脈打ちます。小さいバブルのラベルは、マウスを重ねると表示されます。マップの下にはトピックのタイルが並びます。「AIへのルール」、「プロジェクト」、「あなたの周りの人たち」、ポートレートの各セクション、トピックカード(大きいものが先頭)、そして「出来事と決定」です。タイルにはファクトの数と最新の2行が表示されます(プロジェクトと人物では、先頭の名前が表示されます)。タイルまたはバブルをクリックすると、トピックが前面のウィンドウで開きます。ファクトは1件1行で、新しいものが上、日付は右側に表示されます。検索もでき、クリックするとファクトの全文が展開されます。Mnemaiが学習したファクトには、その場で「どこから?」も表示され、鉛筆アイコンでファイルを開けます。ポートレートの同じ名前のセクション(たとえば、公開用と非公開用の「自分について」)は、1つのトピックにまとめて表示されます。

## ポートレート

ポートレートは、`70 Memory/Profile.md` の冒頭にある2〜3文の紹介文です。あなたが誰で、何をしていて、今いちばん大事なことは何か、をまとめたもので、どのAIにも最初に渡されます。Mnemaiは、あなたについての事実が3つ以上たまると、ポートレートを自動で作ります。材料にするのは、公開されているプロフィールの項目、進行中のプロジェクト、非表示タグのないカードです（お金・健康・プライベートに関する内容はポートレートに入りません）。文章を書くのは学習用に選んだモデルで、モデルがない場合は、事実を短い文にしてそのまま並べます。ポートレートは学習のあとに作り直されます。プロフィールが変わったときはすぐに、カードとプロジェクトだけが変わったときは6時間に1回までです。自分でポートレートを書き換えた場合、Mnemaiはそれ以降手を加えません。作成されたことはログに「ポートレートを作成しました」と表示され、履歴から元に戻せます。

## 10 Now のサマリーと目次

10 Now.md と 70 Memory/Index.md は、記録のたびに Mnemai が自動で作り直すよ。10 Now には、あなたが誰なのか、進行中のプロジェクト、最近の出来事、直近14日間の新しい事実（最大12件）、そして古くなったステータスがまとまっているよ。目次には、すべてのプロジェクト、カード、人物が、検索に使えるキーワードと一緒に載っているよ。これらのファイルを手で編集しても意味がないよ。次に作り直されるときに、変更は消えてしまうからね。

## Mnemaiの学び方

Mnemaiは、あなたの日々の暮らしの中で自分から学んでいきます。アンケートやフォームに記入する必要はありません。許可したソースから事実を見つけて、すぐに記録するか、あなたに確認するかを自分で判断します。学習はバックグラウンドでタイマーに従って進み(頻度はエンジンのモードによって、10分から2時間まで変わります)、Mnemaiのチャットでメッセージを送るたびにもすぐに行われます。初回起動時には、過去90日分の履歴を確認します。

初回起動時、Mnemaiは「MnemaiがほかのアプリやWebブラウザを見てもいいですか?」と尋ねます。「いいえ、Mnemaiのみ」を選ぶと、Mnemaiとの会話とその中での訂正からだけ学び、自分のメモリフォルダ内だけで動作します。Claude Codeのチャット、ノート、ドキュメント、Telegram、ブラウザ、拡張機能は読み取りません。「はい、選択します」を選ぶと、コンピュータ上で見つかったもの(Claude Codeのチャット、ノートフォルダ、ドキュメント、Telegramのエクスポート、ブラウザの履歴、拡張機能)がパスつきの一覧で表示されます。最初はどの項目もチェックされておらず、Mnemaiはチェックした項目だけを読み取ります。メールとカレンダーは、Mnemaiが自分で有効にすることは決してありません。これらにはアドレスとパスワード、または秘密のリンクが必要だからです。

これらはすべて「設定」→「学習」で変更できます。「Mnemaiが見てもよいもの」では、メインのスイッチ「ほかのアプリとブラウザ」がオフのとき、外部ソースのタイルはロックされ、有効にできません。その下の「学習元」では、ソースごとに個別にオン・オフを切り替えられ、一部のソースではパスや除外対象を指定できます。

Mnemaiは、自分のメモリフォルダと、自分が内部で行うモデル呼び出しを読み取ることは決してありません。

## 学習ソース

| ソース | 読み取る内容 |
|---|---|
| Mnemaiでの会話 | Mnemaiのチャットであなたが送ったメッセージ。入力している間にすぐ読み取る |
| Claude Codeでの会話 | Claude Codeの履歴(フォルダ ~/.claude/projects)にあるあなたのメッセージ。新しい行だけが対象。先頭に「[СЛУЖЕБНОЕ-ИМЯ]」のような目印が付いたスクリプトの内部用リクエストはスキップする |
| ChatGPTのエクスポート | ChatGPTのデータエクスポートに含まれるファイル conversations.json |
| あなたの訂正 | AIとの会話での「いや、そうじゃない」「前にも言ったよね」「絶対に〜しないで」が、すべてのAIに共通のルールになる |
| ノートフォルダ | ノートに追加された新しい行。たとえばObsidianのVaultなど。内部用フォルダ(.obsidian、.trash、.git)は除外される |
| メール | IMAP経由で、あなたが送信したメール。引用部分はカットされる |
| Telegram(API経由のやり取り) | やり取り全体(あなたのメッセージと相手のメッセージ)。対象はあなたが選んだチャットのみ。読み取り専用。詳しくは「Telegram」セクションを参照 |
| Telegram(エクスポート)| Telegram Desktopのエクスポートに含まれる、あなた自身のメッセージ |
| カレンダー | .icsファイル、またはiCalの非公開リンク |
| ドキュメント | 選択したフォルダ内の新規・更新されたWord文書、テキスト、ノート(.docx、.txt、.md) |
| ブラウザ履歴 | 読んだページのタイトルを日ごとにまとめたもの(Chrome、Edge、Yandex Browser)。デフォルトでは観察のみ |

## 学習モード

モードはソースごとに設定できるよ。

| モード | 動作 |
|---|---|
| 見るだけ | 学習する内容を表示するだけで、何も書き込まない |
| すべて確認 | 自分では何も書き込まない。Mnemai での会話中はその場で質問し、それ以外の場所からのものは表示するだけ |
| 混合(デフォルト) | 確度の高いものは自分で書き込む。個人的な内容や、記憶と食い違う内容は、Mnemai での会話であれば会話の中でそのまま質問して確認し、それ以外の場所からのものは自分で判断する。確度の低い推測は、もう一度出てくるまで待つ |
| すべて自動 | すべて自分で書き込む。安全策はログとロールバック |

同じ事実が複数のソースで見つかった場合は、そのうち最も慎重なモードが適用されるよ。

## Mnemaiがテキストを理解する方法

ふつうの文章をMnemaiがどう解析するかは、いくつかの方法から選べます（「設定」→「学習」→「テキストの理解に使うもの」）。

| 選択肢 | 内容 |
|---|---|
| Mnemai自身（デフォルト） | いつも話しているデフォルトのモデルを使います。クラウドでもパソコン上のモデルでも、接続済みのものならどれでも使えます。1つも接続されていない場合は、明示的なシグナルだけを拾います |
| モデルなし | 明示的なものだけを拾います：「覚えて …」、訂正、決定（「決めた …」）、ステータスの日付 |
| サブスクリプションのClaude | インストール済みのClaude Code経由で動作します。ツール、フック、MCPは使わず、セッションも保存されません |
| 自分のキー | AnthropicまたはOpenAI互換のAPIを使います。キーはシステムの安全な保管場所（Windowsは DPAPI、macOSはキーチェーン、Linuxはパスワードストア（ある場合））に保存され、メモリフォルダには保存されません |
| パソコン上のモデル | 内蔵モデルまたはOllamaを使います。データが外部に出ることはありません |

クラウドモデルにテキストを送る前に、シークレットはラベルに置き換えられます（「パソコンから外に出るもの」を参照）。

## Mnemaiが「記録する」か「聞く」かを決める仕組み

- 確信度のしきい値は、デフォルトで80%だよ。確信度が80%以上で、個人的な内容ではない事実は、Mnemaiが自分で記録する。60%以上80%未満なら、あなたに確認する。60%未満なら、もう一度出てくるまで待つ。
- 繰り返し出てくると確信度が上がる。60%が2回で84%になり、その事実は記録される。
- お金・健康・個人的なことは、#money、#health、#private のタグが付いたカードに入る。このカードは、「どのAIに何を見せるか」の表で、どのAIからでも隠せる。Mnemaiでの会話の中でそういう話が出たときは、Mnemaiがまずその場で「これは個人的な内容だけど、覚えておく?」と聞く。
- 記憶の矛盾(「カザン在住」と「エカテリンブルク出身」のような場合)は、Mnemaiでの会話ならその場で質問する(「今はこう」「前のが正しい」「どちらも正しい」)。ほかの場所からの場合は、新しい内容が古い内容を置き換える。ただし古い行のほうが多くの情報を含んでいるときは、Mnemaiがそれ以外の部分を残したまま書き直す。以前の内容は「ファクトのアーカイブ」に移る。
- 「今後こういうことは学習しない」を選ぶと、ストップフレーズが追加される。履歴で学習済みの記録を元に戻すと「いいえ」という意味になり、その内容は二度と戻ってこない。
- 「あなたの返事待ち」のキューはない。Mnemaiは質問をためこまない。会話の下に表示される記憶についての質問は、同時に1つまで。次の質問は、その答えのあとに表示される。

## 学習フィードと会話中の質問

「あなたから学習中」フィード(歯車 → 「フィード」)では、Mnemaiが何を読み取り、何を理解し、なぜそう判断したのかを確認できます。たとえば「確信度90%(しきい値80%)、個人的な内容ではないので自分で記録しました」や「お金に関わる内容なので、非表示の領域に記録しました」のように表示されます。記憶のためにあなたの一言が必要なときは、会話の下に「記憶のために確認させて」カードがボタン付きで表示されます。答えはその場ですぐに記録されます。学習した各行には「どうして知っているの?」があり、情報源、あなたの言葉、何回出てきたか、なぜ記録したのかを確認できます。

## チャットとモデル

Mnemaiは、どんなモデルとでもチャットできます。すべてのモデルは対等です。モデルの選択はチャット左上にあり、メニューには2つのグループがあります。

- クラウド — インターネット経由で動きます。キーで使う方法(Anthropic、OpenAI、Gemini、OpenRouter、DeepSeek、YandexGPT。モデルの一覧はMnemaiがプロバイダから取得します。YandexGPTだけはYandex Cloud AI Studioのカタログから取得します)と、サブスクリプションで使う方法(Claude Code)があります。
- このコンピュータ — 無料で、インターネットなしで動き、外部には何も送信されません。内蔵モデル(llama.cpp)、Ollama、Strataがあります。

DeepSeekは、platform.deepseek.com で発行したキーで接続します。YandexGPTは、Yandex Cloud AI Studioのサービスアカウントの APIキー(ロール ai.languageModels.user)と、そのサービスアカウントを作成したカタログのIDで接続します。接続ウィンドウには2つの入力欄があります。YandexGPTのモデルは、Alice AI LLM、YandexGPT Pro 5.1、YandexGPT Pro 5、Alice AI LLM Flash、そして同じカタログにある DeepSeek V4.1 Flash と Qwen3.6 35B です。Strataは、大規模モデル(Qwen、DeepSeek)を自分のグラフィックボードで動かすための、独立した無料プログラムです(github.com/Niko1221/Strata)。Strataをインストールして、strata launch コマンドでモデルを起動してね。起動時にMnemaiが 127.0.0.1:8080 で動いているStrataを自動で見つけます。別のアドレスを使うときは、Strataの接続ウィンドウで指定してね。

同じ2つのグループは、「設定」→「AIとモデル」にもあります。返答の長さの上限(「設定」→「エンジン」)はすべてのモデルで共通で、サブスクリプションで使うClaudeにも適用されます。

メモリとあなたのルールはメッセージごとに適用され、各モデルには見ることを許可された内容だけが渡されます。会話にはそれぞれ1〜3語のタイトルが付きます。タイトルを変えるには、タイトルの横の鉛筆アイコンを押すか、タイトルをダブルクリックするか、リストの会話メニューから操作してね(Enter で保存、Escape でキャンセル)。新しい会話では、最初のメッセージを送る前にタイトルを決められます。タイトルはそのメッセージと一緒に保存されます。手動で名前を変えた会話のタイトルは、Mnemaiが二度と変更しません。リストには、最終更新日時と消費したトークンも表示されます。リストは日付またはトークン数で並べ替えられ、「AI」フィルタを使うと、特定の1つのモデルとの会話だけを表示できます。

空の会話にある「Mnemaiから始めてもらう」ボタンを押すと、モデルがあいさつして、メモリをもとに何から始めるかを提案します。出来事を「最近」と呼ぶのは、その日付が実際に最近であるときだけです。1か月より前の決定については、見直すことを提案します。

## セッション

「新しいセッション」ボタンは、リストの上部にある「新しい会話」の下にあるよ。セッションとは、最後にこのボタンを押したあとに始めたすべての会話のこと。「新しい会話」は今のセッションの中で会話を開き、「新しいセッション」は新しいグループを始める。リストでは、同じセッションの会話が左側の線でひとつにまとまっていて、グループのラベルと会話の数が右側に表示される。いちばん上は「現在のセッション」、過去のものは「セッション · 10月24日」(最後の会話の日付)という表示になる。ラベルをクリックするとグループが折りたたまれ、折りたたんだ状態は記憶される。「新しいセッション」を押した直後は空の行は出ず、新しいセッションに最初の会話ができるまでは、いちばん上のグループが「現在のセッション」のまま残る。ラベルの横にある ⋮ メニューには、「名前を変更」(グループに好きな名前をつける)と「削除」(セッションを会話ごと削除する。ピン留めした会話は残り、学習した内容はメモリに残る)がある。セッションが導入される前に始めた会話は、リストの末尾にひとつの別のセッションとしてまとめられ、ピン留めした会話はグループの外、いちばん上に表示される。検索、トークン数での並べ替え、日ごとのグループ表示のときは、セッションのない通常のリストになる。

ボタンの隣には「?」がある。アニメーションで、ひとつの会話に長くとどまるとなぜコストがかさむのか、そして新しい会話と新しいセッションの違いを見せてくれる。

どの会話も、モデルに送るのはその会話自身の履歴だけ。だから、新しいセッションの会話はまっさらなコンテキストから始まる。モデルに渡されるのはメモリとルールで、過去の会話のやり取りは渡されない。長い会話は返信のたびに送る履歴がどんどん増えていくので、話題を変えるときは新しい会話か新しいセッションを始めたほうがお得。過去の必要なことは、Mnemai がすでにメモリに書き留めているよ。

同じモデルのその会話での最初の返信と比べて、ある返信のコストが3倍になると(入力トークンにキャッシュと返信を含む)、その返信の下に「会話のコストが高くなっています」というカードが表示される(コンピューター上の無料モデルでは表示されない)。カードには、最初の返信と最後の返信を表す2本のバーと、何倍高くなったかが出る。「メモリを更新して新しいセッションを始める」ボタンは、まず会話全体を一度にまとめて学習し、そのあとまっさらなコンテキストで新しいセッションを始める。以前に学習済みのメッセージは、このとき重複とは見なされない。学習をしていない会話では、このボタンは新しいセッションを始めるだけ。「今後表示しない」を選ぶとこのヒントが完全にオフになり、戻したいときは歯車アイコンの設定(「高コストな会話のヒント」)から。カードの×は、その会話でだけカードを隠す。

## 応答のしかた

「設定」→「応答のしかた」では、名前、呼びかけ(タメ口か敬語か)、返答の長さ(短く、要点だけ、詳しく)、性別(語尾の使い分け用:「正しいです」の言い回しなど)、そして性格を選べるよ。選択肢はすべてタイルになっていて、右側には「返答の例」が表示される。パイロット運用についての同じ質問に対する返答が、設定を変えるたびにすぐ切り替わり、名前は入力しているそばから反映されるよ。性格は「やさしい」「ビジネスライク」「検証つきで厳しめ」の3種類で、メダルのデザインになっていて、確認の厳しさが1〜3の目盛りで示されている。その下には、セットと、グループごとの詳しいルールが並んでいるよ。

## モデルがメッセージごとに把握していること

モデルは返答する前に、次の情報を受け取っているよ:
- あなたとどう接するか。"回答スタイル"セクションのルール(キャラクター、呼び方、あなた自身の言葉)
- このモデルが見ることを許可されている記憶(記憶の先頭部分と、質問に関連する行)
- Mnemaiがいま、どのような状態になっているかという情報。どこで学習しているか、どのモードか、何でテキストを理解しているか、記憶に何件の記録があるか
- 今日の日付
- Mnemai自身についての質問には、このナレッジベースの該当セクション

モデルはMnemaiとして答え、自分の機能についてはMnemaiにできることだけを話すよ。Mnemaiが動いているエンジンの機能(たとえばClaude Codeのツール)は、Mnemaiには含まれないよ。

## ファイルとドキュメント(PDFも含む)

ファイルは、入力欄の下にあるクリップのボタンか、ウィンドウへのドラッグ&ドロップで添付できるよ。1ファイルにつき25 MBまで。Mnemaiは添付されたファイルを会話の隣に保存して、テキストの抽出も自分でパソコン上で、無料で行うよ。

| 形式 | Mnemaiの処理 |
|---|---|
| テキストレイヤーのあるPDF | ページごとにテキストを抽出する(ページ番号つき) |
| テキストのないスキャンPDF | パソコン上でテキストを認識(RapidOCR)して、最大40ページまで、どのモデルにもテキストとして渡す。文字種はインターフェースの言語に合わせる:ロシア語ならキリル文字(と英語)、ヨーロッパ言語ならダイアクリティカルマーク付きのラテン文字、中国語と日本語なら中国語と英語。何も認識できなかった場合はファイルをそのままモデルに渡す。この形式を読めるのは、APIキーを使ったAnthropicだけ |
| パスワード付きPDF | ファイルがパスワードで保護されていることを知らせて、パスワードの解除を提案する(「印刷」→「PDFとして保存」) |
| Excel(xlsx、xls)、CSV、TSV | シートごとの表にする。1シートにつき最大2000行 |
| Word(docx)、PowerPoint(pptx)、OpenDocument、RTF、HTML | テキスト。Wordの表は行ごとに、セルは「 \| 」でつなぐ |
| テキストファイルとコード(txt、md、json、xml、pyなど) | テキストをそのまま使う |
| 画像(png、jpg、gif、webp) | 画像としてモデルに渡す(見えるのはAnthropic、OpenAI互換プロバイダーのモデル、画像対応のOllama)。さらに、画像内のテキストもパソコン上で認識するので、どのモデルでもその内容を受け取れる |
| その他の形式 | モデルにはファイル名だけが渡される |

ドキュメントの全文は会話の隣に保存されるよ。「正確 ↔ 節約」スライダーのいちばん正確なステップ以外では、モデルにはファイル全体ではなく、ドキュメントの冒頭と今の質問に答える部分が渡される。いちばん正確なステップでは全文がそのまま挿入されるけど、60,000文字までだよ。これでPDFを使って、要約する、本文から答えを探す、請求書の情報や数字を取り出す、添付した2つのドキュメントを比較する、表を読み解く、といったことができる。

ファイルの作成と編集、PDF・Word・Excelの作成、既存のWordとExcelの編集、PDFの結合・分割・回転・切り出し、パスを指定したファイルの読み取りは、ファイル操作の機能だよ(下のセクションを参照)。Mnemaiがファイルでやらないこと:PDFのフォームへの入力、プログラムやスクリプトの実行。

## インターネット

入力欄の下にある「インターネット」のスイッチは、検索を許可するだけで、メッセージのたびに検索を実行するわけではありません。Mnemaiが検索するのは、最新の外部データがないと確実に答えられないときだけです。たとえば、価格、為替レート、ニュース、最新バージョン、スケジュール、「今」や「今日」に関する質問、そしてあなたが「探して」「検索して」とはっきり頼んだときです。Mnemai自身のこと、あなたのこと、一般知識(「〜とは?」)、与えられたテキストに対する作業では、ネットには接続しません。メッセージ内のリンクは、スイッチがオフでも必ず読み込まれます。リンク先のページやVPNのサブスクリプションは、インターネット上のアドレスしか開けません。このコンピューター、自宅やオフィスのネットワーク、Mnemai用の内部アドレスはブロックされます。

検索は無料で、キーも不要です。まずddgsライブラリ経由でBingとYahooを使い、そのあとDuckDuckGo、Bing、Yandex、Wikipediaに直接アクセスします。質問のキーワードの大半と一致しない結果は除外されます。ページの読み込みとクリーニングはコンピューター上で行われ、モデルには番号付きの抜粋が渡され、[1]、[2]のように参照されます。情報源は回答の下に表示されます。インターネットがオフで、質問が明らかに最新データを必要とする場合、Mnemaiは自分の知っている範囲で答えたうえで、検索をオンにするよう提案します。

## 精度か節約か

「設定」→「エンジン」→「詳細設定」→「精度 ↔ 節約」は、5段階のスライダーです。初期設定は真ん中です。精度寄りにすると、質問と照らし合わせるメモリやドキュメントの断片が増え、モデルも確認の質問をしやすくなりますが、そのぶん回答のコストは上がります。節約寄りにすると、照らし合わせる量が減り、モデルは確認しないと答えられないときだけ質問します。

| 段階 | リクエストに含めるメモリ | ドキュメントの照合範囲 | 会話 | 確認の質問 |
|---|---|---|---|---|
| 最も節約 | 2,000文字 | 最大3,500 | 最大8,000 | どうしても必要なときだけ |
| 節約 | 3,000 | 最大5,000 | 最大11,000 | どうしても必要なときだけ |
| バランス(初期設定) | 4,200 | 最大7,000 | 最大14,000 | 必要なとき |
| 精度重視 | 8,000 | 最大12,000 | 最大20,000 | 多め |
| 最高精度 | 16,000 | 全文 | 全文 | 少しでも不明な点があるとき |

最高精度の段階以外では、メモリは冒頭部分と、質問に関係のある行だけが送られます。会話は直近6件のメッセージをそのまま含め、それより古いものは400文字に短縮されます。ドキュメントやWebページは、関係する部分だけが使われます。回答の下には、節約できたトークン数が表示されます(目安:1トークンあたり約3.5文字で計算)。153,000文字の契約書で測定したところ、節約なしでは入力が29,643トークン、節約ありでは6,159トークンで、正しい答えを返したのは節約ありの場合だけでした。

## ボタンで答える質問、セカンドパス、引用

モデルが確認したいことがあるときは、質問を1枚のカードで1つだけ出す。カードには、質問そのもの、なぜ聞くのかを一行で示した理由、そして2〜4個の選択肢が縦に順番に並ぶ。選択肢にはそれぞれ、選んだらどうなるかの短い説明が付く。選択肢はクリックするか、キーボードの数字キーで選べる。カードの下部には、自分の言葉で答える入力欄もある。答えたあとは、選んだ選択肢にチェックマークが付く。カードの歯車アイコンからは、選択肢つきの質問をするか、選択肢に説明を付けるか、必要なときだけ質問するか、を設定できる。「セカンドパス」(設定内)をオンにすると、モデルは下書きをあなたに見せる前に、あなたのルールとメモリに照らして確認する。回答の一部を選択すると、次のメッセージでその部分を引用できる。回答の下にある「役に立った」ボタンは、どんな形式の回答があなたに合っているかを伝えるシグナルになる。マークした回答は、モデルが形式のお手本として使う。

## 繰り返しのタスク

似たタスクが2回目に出てきたとき(毎回提案する、または一切提案しない、は設定で変えられます)、Mnemaiはレシピの保存を提案します。次からは説明し直したり、確認のためにトークンを使ったりしなくて済みます。レシピには、目的・入力データ・手順・結果の形式・チェック項目・やってはいけないことを書き、90 System/Recipes に保存されます。次に似たリクエストが来たら、Mnemaiがそのレシピに沿って自動で実行し、回答の下に「レシピ「…」に従って実行」と表示されます。似ているかどうかは、単語の語幹が一致するかどうかで、パソコン上で判定されます。

## 用語のヒント

「ヒント」をオンにすると(入力欄の下の「+」メニューから)、モデルが回答に短い用語集を添えます。対象は、わかりにくい用語と、回答に出てくるすべての名前です。人、会社、プロダクト、サービス、コミュニティ(たとえば Show HN)が含まれます。ただし、あなた自身と、あなたが自分で話した人は除きます。Mnemai は用語集を切り離し、回答の中のそれらの言葉に下線を引いて、カーソルを合わせると説明を表示します。

## コンソーシアム

どの回答の下にもある「いろいろなAIと議論する」を押すと、まず「誰と議論する?」というウィンドウが開く。表示されるのは、回答を書いた本人を除く、接続済みのすべてのモデル。おすすめは最初からチェックされていて、相手は最大3つまで選べて、最初にチェックしたAIが最後にまとめる。回答を書いたAIはその回答を擁護し、相手側はどこが間違っているか、足りないか、もっと良い案がないかを探す。最後にまとめとして、その回答が通用するかどうか、そしてどうすべきかが示される。接続しているAIが1つだけの場合は、そのAIのモデル同士(たとえばSonnetとOpus)が議論する。これは通常のコンソーシアムをディベート形式にしたもので、続けることも、止めることも、終わらせることもできる。

入力欄の下にある「コンソーシアム」ボタンを押すと、2〜4つのAI(内蔵のAIを含め、接続済みのモデルならどれでもOK)による議論が、1〜20ラウンドの範囲で始まる。AIたちは順番に話し、お互いの発言を見ながら名前を呼びかけ合い、最後の1つがまとめを出す。まとめには、どこで意見が一致したか、どこが分かれたか、どうすすめるかが入る。メッセージの上には円卓が表示されて、今誰が話しているか、次は誰かが分かり、「一時停止」「再開」「終了」「もう一度議論」のボタンが並ぶ。「停止」(回答中は送信ボタンがこれに変わる)を押すと、今話しているAIをその場で止める。そこまでの発言は「中断」と表示されて残り、ほかのAIは「再開」を待つ。メンバーやラウンド数は、議論の途中でも変更できる。

各参加者には、会話の全体が渡される。直近16件のメッセージはそのまま、それより前のものは要約して、添付した資料は質問に関係する部分、画像から読み取ったテキスト、画像そのもの、PDFも含まれる。形式は次のとおり。相談、ディベート、ブレインストーミング、レッドチーム、そして「容赦なしレビュー」(アイデアや履歴書、文章を厳しく叩く形式で、まとめは「N/10」の評価から始まる)。まとめの下の「シェア」を押すと、結果をカード状の画像にして共有できる。

議論中にあなたが書き込むと、今話しているAIは止まり、会話はあなたのメッセージから続く。まだ何も話していないAI(サービスが固まっている場合)は、すぐに外される。APIキーが合わなかったり残高が尽きたりした参加者は、その旨を一度だけ伝えて、以降の議論には参加しない。その場合は別のAIがまとめを担当する。各参加者には、それぞれのアクセス権限の範囲内でメモリが渡される。コンソーシアムは、すでに進行中の会話にも後から追加できる。


コンソーシアムのウィンドウは、最初はシンプルな表示になっている。誰を会議に呼ぶか(2〜4つのAI、カードの番号が発言順)、議論の形式、そして選んだ参加者が発言順に並ぶ「ライブ円卓」だ。「詳細設定」を押すと、そのほかの項目が開く。ラウンド数、役割、誰がまとめるか、発言の長さ、ファクトチェック、ラウンドの計画で、どの項目にも「?」があって説明が見られる。「シンプル表示」を押すと、元のシンプルな表示に戻る。

ファクトチェック(デフォルトでオン):参加者が事実、数字、日付、最新の情報を根拠にするときは、自分でインターネットを検索する(1ターンにつき最大2回)。そして [1]、[2] のように出典リンクを付けて答える。出典は発言の下に表示される。意見やアドバイスについては検索しない。検索ありのターンは長くなる。モデルが、検索の前と後で2回答えるためだ。オフにするには、詳細設定の「ウェブを検索」を使う。

「コンソーシアム」ボタンの歯車を押しても、同じ設定が開く。

| 設定 | 選択肢 |
|---|---|
| 形式 | 相談:自分の回答 → 確認 → 改善 → 意見が分かれた点 → 共通の回答。ディベート:参加者が交互に賛成と反対に分かれ、立場 → 反論 → 評決。ブレインストーミング:批判なしでアイデアを出す → 他の人のアイデアを発展させる → 上位3つ(理由、最初の一歩、リスク)。レッドチーム:あなたの計画への攻撃 → 穴のふさぎ方 → リスクの一覧と対策 |
| 役割 | 参加者ごとに:役割なし、懐疑派、実務家、財務担当、法務担当、クリエイター、アナリスト、顧客 |
| まとめ担当 | 順番が最後の参加者、または選んだ参加者:最後のラウンドでは、その人が最後に話す |
| 発言の長さ | 短め(80語まで、まとめは120語まで)、ふつう(150語と180語)、じっくり(300語と350語) |

ウィンドウの下部には図が表示される。発言順に参加者が並ぶ円卓、ディベートでの立場、まとめ担当の横にあるトロフィー、そして選んだ形式のラウンド計画だ。形式、長さ、役割は、次回の会議用に保存される。

## ファイル操作

チャットのモデルはファイルを扱えます。ファイルの読み取り（PDF、Word、Excel、PowerPoint も対応。スキャンした書類や画像はパソコン上で文字認識されます）、フォルダの確認、キーワードでのファイル検索、テキストファイル（.md、.txt、.csv、.json、.html）の作成や書き換え、ファイルの一部の修正、見出し・リスト・表を含むテキストから PDF・Word・Excel の文書を作ること、メモリへの1行の書き込みができます。クラウドのモデルでもパソコン上のモデルでも、どのモデルでも使えます。

作成できる文書：

| 種類 | 内容 |
|---|---|
| Word (.docx) | 書式を保ったままテキストを置き換えます。太字の単語が含まれていても、ファイル内部で文が複数の断片に分かれていても、該当のフレーズは見つかります。新しいテキストには、元のフレーズが始まっていた位置の書式が適用されます。ヘッダー・フッターと脚注も対象です |
| Excel (.xlsx, .xlsm) | セルの値と数式（"Лист1!B3 = 1500"、"C7 = =SUM(C1:C6)"）、セル内テキストの置換に対応。ほかのシートや書式、数式はそのまま残ります。グラフ、画像、ピボットテーブルを含むブックは、保存時に失われてしまうため Mnemai では編集しません |
| PDF | 複数のファイルを結合、必要なページだけを好きな順番で残す（同じ方法で切り出し・削除・並べ替えも可能）、ページを 90、180、270 度回転、複数の部分に分割。元のファイルは変更されず、既存のファイルが上書きされることもありません |

初期設定では、Mnemai はアクションをすぐに実行します。「設定」→「プログラム」→「ファイル操作」で「操作のたびに許可を確認する」をオンにすると、返答の下に「Mnemai からのリクエスト」カードが表示され、どのファイルに何をするのかが示されます。ボタンは「はい」「この会話では常にはい」（この会話では同じ種類の操作を以後確認しません）「いいえ」です。操作が終わると、会話に「ファイルを作成しました …」という行と「フォルダで表示」ボタンが残り、モデルは返答を続けます。プログラムが起動されることはなく、インターネットに送信されるものもありません。

操作できる場所：メモリフォルダと、「設定」→「プログラム」→「ファイル操作」で追加した作業フォルダです。同じ場所でファイル操作をまとめてオフにすることもできます。内部用の .mnema フォルダには触れません。メモリ内のノートは、モデルが自分の権限の範囲で読み取るので、非表示のトピックは非表示のままです。文書が既存のファイルを上書きすることはなく、新しいファイルには「отчёт (2).pdf」のような名前が付きます。書き込みはすべて元に戻せます。「メモリ」→「履歴」から、メモリ内も作業フォルダ内も取り消せます。PDF は Edge、Chrome、Chromium のいずれかを使い、ウィンドウを開かずに作成されます。Edge は Windows 10 と 11 のどちらにも入っています。macOS と Linux ではこのうちどれかが必要です。

## 会話から学習しない

入力欄の下にある「学習しない」スイッチをオンにすると、その会話は最初のメッセージから、メモリに何も学習させません。モデルはこれまでどおりメモリを参照できますが、会話から新しい内容が書き込まれることはなく、その会話で「役に立った」を付けても、学習には反映されません。

## 音声とミーティング

入力欄の下にあるマイクボタンで、コマンドを話しかけたり、ミーティングを録音したりできるよ。コマンドはマイクで録音され、パソコン上で文字起こしされてメッセージとして送られ、音声は削除される。ミーティングの録音ではマイクとパソコンの音声を2チャンネルで記録するので、文字起こしを見れば誰が話しているか分かる。音声や動画をチャットにドラッグ&ドロップするだけでもOK（iPhoneの .mov、.mp4、.avi、.3gp、.m4v なども使える）。認識モデルがまだない場合は、一度だけダウンロードする必要がある（約0.5 GB、インターネット接続が必要）。その際は Mnemai が知らせてくれる。文字起こしはパソコン上の faster-whisper で行う（small または medium モデルがダウンロード済みならそちらを使用）。OpenAI のキーを使ってクラウドの Whisper で文字起こしすることもできる。料金は1分あたり $0.006、1時間でおよそ $0.36 だよ。"おまかせ"モード（デフォルト）では、最初の1分でパソコンの処理速度を測り、ミーティングの長さ、または10分以内に終わらなさそうなら、クラウドを使うかどうか確認してくる。音声と Расшифровка.md は 80 Meetings に残り、チャットには文字起こしと短い要約が届いて、あなたの発言は学習に使われる。ミーティング録音ウィンドウの右上にある"設定"から、設定 → ミーティング録音 に移動できる。そこではミーティングの流れが4つのステップで表示されている。録音（音声を保存するかどうか）、文字起こし（どこで、どれくらいの精度で行うか）、要約（どのモデルで要約するか）、メモリ（あなたの発言から学習する）。ステップをクリックすると、下に説明と設定が表示される。上部には用意されたプリセットがある。"プライベート"（すべてパソコン上で処理し、音声は削除）、"バランス"（Mnemai におまかせ）、"高速"（クラウドの Whisper）。要約モデルは録音ウィンドウでも選べるよ。

## パソコン内蔵モデル

Mnemaiにはllama.cppのサーバーが組み込まれているよ。Hugging FaceのGGUFモデルを5つのグループ、全13種類から選べる。軽量(Gemma 3 1B、Qwen2.5 1.5B、Llama 3.2 3B)、バランス型(Gemma 3 4B — おすすめ、Qwen3 4B、Phi-4 mini)、高性能(Qwen2.5 7B、Llama 3.1 8B、YandexGPT 5 Lite 8B)、特殊(Qwen3 4B Thinking、Qwen2.5 Coder 7B)、大型(Gemma 3 12B、Mistral Small 3.2 24B)。それぞれ、用途、サイズ、必要なメモリ、そして今の回線でのダウンロード時間が表示される。ダウンロードは一時停止と再開ができる。モデルは ~/.mnema/models に保存される。インターネットなしで、無料で使えるけど、クラウドのモデルよりは性能が控えめだよ。

パソコン内のモデルを選んでいる間は、チャットのヘッダーに温度計が表示される。プロセッサの負荷、モデルの使用割合、メモリ、そしてシステムが提供していれば温度が見られる(Windowsでは取得できないことがあり、Linuxでは通常取得でき、macOSでは取得できない)。モデルが1分間パソコンを熱くし続けると、Mnemaiが自動でモデルの優先度を下げて、そのことを知らせてくれる。「負荷を下げる」と「モデルを停止」のボタンもあるよ。

## エンジン:トークンと負荷

「設定」→「エンジン」に、3つのモードがあるよ。

| モード | 精度 ↔ 節約 | 応答の長さ | コア数 | コンテキスト | 学習 |
|---|---|---|---|---|---|
| 節約 | 節約寄り(メモリ3,000文字) | 最大1,000トークン | 4分の1 | 4,096 | 2時間に1回 |
| バランス(デフォルト) | バランス(4,200) | 3,000 | 半分 | 8,192 | 30分に1回 |
| 最大 | 最高精度(16,000、短縮なし) | 8,000 | 1つを除くすべて | 16,384 | 10分に1回 |

細かい調整は1列にまとまっているよ。「精度 ↔ 節約」、最長の応答、月間の上限、CPUのコア数、どれだけ覚えておくか、の5つ。スライダーを手動で動かすと、モードは「カスタム」に切り替わるよ。月間の上限はクラウドのトークンだけを数えていて、上限に達するとクラウドへのリクエストはわかりやすいメッセージとともに止まるけど、パソコン上のモデルはそのまま動き続けるよ。サブスクリプションで使うClaudeの応答の長さは制限できないよ。

その下に「バックグラウンド」という別のブロックがあるよ。「作業を妨げない」はパソコン上のモデルの優先度を下げて、「バックグラウンド学習」はMnemaiが学習元をどのくらいの頻度でチェックするかを決めるよ。

## どのAIに何を見せるか

「設定」→「セキュリティ」→「どのAIに何を見せるか」は表になっています。列がAI、行がメモリの各部分で、さらに非公開トピック(お金、健康、個人的なこと)のブロックがあります。非公開トピックは、許可した部分からも取り除かれます。クリックすると、その場で保存されます。列の下にあるスイッチを切ると、そのAIを完全にオフにできます。初期状態では何も隠されておらず、どのAIでも新しい内容を受信トレイに追加できます。

| AI | 見える範囲 | 追記できる範囲 |
|---|---|---|
| パソコン上のモデル(内蔵、Ollama、Strata) | すべて | 受信トレイ |
| Claude、Claude Code | すべて | 受信トレイ、決定事項、プロジェクト、カード、人物、ルール |
| ChatGPT | プロフィール、ルール、プロジェクト、カード、決定事項 | 受信トレイ |
| OpenRouter、DeepSeek、YandexGPT | プロフィール、ルール、プロジェクト、カード、決定事項 | 受信トレイ |
| Gemini | プロフィール、ルール、カード | 受信トレイ |
| Cursor | ルール、プロジェクト | 受信トレイ |

パソコン上のモデルはすべてを見られます。パソコンからは何も外に出ないからです。お金、健康、個人的なことは、初期状態では「カード」を開放しているすべてのAIに見えています。特定のAIからトピックを隠したいときは、そのAIの列で「表示」をクリックしてください。「非表示」に切り替わります。

見出しに付けた非公開タグ(例:「## お金 #money」)は、その見出しと配下の内容をすべて隠します。タイトルに付けたタグ「# お金 #money」や、ファイルのプロパティ(tags)に指定したタグは、ファイル全体を隠します。ロシア語のタグ(#деньги、#здоровье、#личное)も使えて、大文字・小文字は区別されません。Obsidianが書き出す形式のプロパティ(tagsをリストで指定する形)にも対応しています。非公開カードのステータスを変更すると、同じタグが付いたままイベントフィードに記録されるので、そちらも隠されます。

## パソコンから外に出る情報

クラウドAIへのリクエスト(チャット、コンソーシアム、セカンドパス、会話タイトルの生成、学習ブレイン、ポートレート)や、検索エンジンへのリクエストを送る前に、カード番号(ルーンアルゴリズムでチェック済みのもの)、パスワード、PINコード、CVV、APIキー、VPNのトークンやキー、電話番号、パスポート、SNILS、INN、口座番号は、[ТЕЛЕФОН-1] のようなラベルに置き換えられます。返ってきた回答は、パソコン上で本物の値に戻されます。この機能は「設定」→「セキュリティ」でオンにできます。他社のクラウド上で動く学習ブレインには、チャットのAIと同じルールでメモリが渡されます。非表示にしたトピックは送られません。外へ出るリクエストはすべてログに1行ずつ記録されます。記録される内容は、いつ、誰に、何のために(チャットの回答、学習、ポートレート、会話タイトル、インターネット検索)、何文字、利用可能なメモリのうちどれだけ、何を非表示にしたか(個数のみで、値は記録されません)です。送信されなかったリクエスト(プログラムがない、キーがない、接続がないなど)は、ログに記録されません。左下の「メモリ」カードにある「今週の外部送信」では、過去7日間のレポートを確認できます。

## パスワードでメモリを暗号化する

「設定」→「セキュリティ」→「パスワードでメモリを暗号化」から設定できる。Windows、macOS、Linux で使える。初回起動時にも「メモリをパスワードで保護しますか?」というステップで同じ設定を案内する。デフォルトはパスワードなしで、自分でパスワードを入力するか、「安全なパスワードを生成」を押して作ることもできる。暗号化したメモリを Google Drive、Dropbox、自分のフォルダ、またはステーションと同期すると、送られるのは暗号化されたファイルだけ。別のパスワードのコピーは受け付けず、あなたのメモリを上書きすることもない。Mnemai は、ノートや、あなたが話したこと・したことを記録したサービスファイル(会話、添付ファイルのテキスト、ジャーナルとロールバック用のスナップショット、学習の履歴、外部に送信された内容のレポート、ポートレート)を自分で暗号化する。パスワードがなければ、フォルダをコピーしても読めない。

| | |
|---|---|
| 仕組み | ランダムなメモリキー(AES-256-GCM)でファイルを暗号化し、パスワードから scrypt でこのキーを暗号化する。どちらも .mnema/crypto.json に保存される |
| パスワード | 8文字以上。復元はできないので、忘れるとメモリは取り戻せない。変更はいつでもでき、その際にファイルが書き換えられることはない |
| 「このコンピューターで記憶する」 | キーはOSの安全な保管領域に保存される(Windows は DPAPI、macOS はキーチェーン、Linux はパスワードストアがあればそれ、なければホームフォルダ内のあなただけがアクセスできるファイル)。Mnemai は確認なしで開く。オフにすると、起動のたびにパスワードを聞かれ、入力するまで Mnemai は何も表示せず、学習もしない |
| 暗号化されないもの | バイナリファイル(PDF、Word、画像、会議の録音)。他のプログラムで開くため。パスワード入力前に必要な設定(言語、モデル、AIのアクセス権限)。他のプログラムのフォルダ(.obsidian など) |
| デメリット | Obsidian などのエディタでは、暗号化されたノートは開けない。他のプログラムがフォルダに書き込んだノートは、次に Mnemai を開いたときに暗号化される |
| 途中で止まった場合 | ファイルは1つずつ暗号化される。まず隣に新しいファイルを書き出し、同じ内容で読み戻せるか確認してから、古いファイルと入れ替える。途中でパソコンの電源が切れても、一部のファイルが暗号化されないまま残るだけで、すべて読み取れる。次に Mnemai を開いたときに、残りを暗号化する |
| Claude Code、Cursor(MCP) | Mnemai が起動しているか、このコンピューターでパスワードが記憶されていれば、これまでどおりメモリを受け取れる |

「暗号化を解除」(同じスイッチ。パスワードが必要)を押すと、通常のファイルに戻る。

Windows では、OS標準の暗号化機能(EFS)も使える。あなたにも Mnemai にも他のプログラムにも透過的に動作し、キーは Windows のユーザーアカウントになる。Windows Home では使えない。

## 履歴とロールバック

メモリへの書き込みはすべてログに記録されます。誰が、何を、いつ書いたかが残ります。「メモリ」→「履歴」から、どの変更もボタン1つで元に戻せます。その後にファイルが編集されていても、ロールバックで取り消されるのはその書き込みの行だけで、あとから加えた編集はそのまま残ります。ロールバックを拒否するのは、その行自体がすでに手作業で修正されている場合だけです。ファイルをその日初めて編集する前に、Mnemai は 95 Saves にコピーを保存し、直近の2つが保持されます。チャット、学習、ほかのAIからの書き込みは1件ずつ順番に処理されるので、同時に書き込んでも互いに失われることはありません。Mnemai のエディタで開いているファイルが編集中に変更された場合、Mnemai は上書きせず、開き直すよう求めます。

ルールが別の言い方で伝えられた場合（「会話の要約は短くして」と「要約は短くまとめて」など）、Mnemai は2行目を追加せず、既存の行を新しい言い方に書き換えます。

## 他のAIとつなぐ

- Claude Code、Claude Desktop、Cursor:「設定」→「AIとモデル」→「他のAIのメモリ」→ タイルの「接続」。MCPで接続するよ。使えるのは memory_context、memory_search、memory_remember、memory_stale、memory_journal、memory_undo。コンテキストは最大9,000文字ごとに分割される。Cursorにはルールとプロジェクトだけが渡され、書き込みはしない。接続済みかどうかはタイルで確認できる。
- ChatGPTとGemini:自分のキーを使って、Mnemaiのチャットから利用する(「設定」→「AIとモデル」→ OpenAIまたはGeminiのタイル →「キーを入力」)。ブラウザ拡張機能はない。AI自身にできないことは、すべてMnemaiがこのコンピューター上で行うよ。
- MCP経由の場合、各AIがジャーナルで見られるのは、そのAIが読んでよい内容の記録だけ。取り消せるのも、そのAI自身の記録だけだよ。ポータブル版からアップデートすると、ClaudeとCursorの接続は自動で新しいプログラムに切り替わる。
- モデル:「設定」→「AIとモデル」。一番上が「現在の応答モデル」で、デフォルトモデルのメダルとその選択が表示される。その下の「モデル」は2つのセクションに分かれている。「有料」(サブセクション「サブスクリプション」はサブスクリプションで使うClaude、サブセクション「APIキー」はChatGPT、Claude・APIキー、DeepSeek、Gemini、OpenRouter、YandexGPT。料金はサブスクリプションとは別に、使った分だけ支払う)と「無料」(内蔵モデル、Ollama、Strata。このコンピューター上で動く)。左上のモデルメニューと、初回起動時の「どのAIと話す?」のステップも同じように分かれている。タイルはどれも対等なメダルで、各提供元のカラーになっている。内蔵モデル、サブスクリプションのClaude、Claude・APIキー(Anthropic)、ChatGPT(OpenAIのAPIキー)、Gemini、OpenRouter、Ollama。ChatGPTとGeminiはAPIキーでしかつなげられない。ChatGPT PlusやGemini Advancedのサブスクリプションではキーは発行されないし、APIの料金はOpenAIとGoogleにそれぞれ別途、使った分だけ支払うことになる。接続済みのタイルはカラーで「接続済み」と表示され、未接続のタイルはグレーになる。タイルのボタンは1つだけ。「キーを入力」を押すと、タイルの中にそのままキー入力欄が開く →「保存してモデルを探す」または「キャンセル」。Ollamaの場合はアドレス、内蔵モデルの場合は「選んでダウンロード」になる。サブスクリプションのClaudeは、コンピューターにClaude Codeがあれば自動で表示される。Mnemaiは、プログラムの検索パスだけでなく、インストーラーが入れる場所(公式インストーラー、npm、WinGet、Volta、bun、Homebrew)や、Claude Desktopアプリの中も探すよ。Claude Codeは見つかったのにアカウントにログインしていない場合、タイルに「ログイン」ボタンが出る。押すとClaude Codeのウィンドウが開くので、サブスクリプションでログインして、「もう一度確認」を押してね。見つからない場合は「インストール方法」が表示される。接続済みのAIにはそれぞれ「オフにする」ボタンがあり、押すとそのAIはすべてのモデル一覧(チャット、コンソーシアム、「メモリあり・なし」)から外れる。キーと設定は残り、「オンにする」で元に戻る。AIは接続されているのにアカウントの問題で応答しない場合(Claudeの利用制限やサブスクリプションが切れた、残高がない、Claude Codeのログインが古くなった、キーが受け付けられない)、タイルに「動作していません」と原因が表示され、そのAIは一覧から外れて、次に使えるAIが応答する。「もう一度確認」ボタンは、ごく小さな本物のリクエストを送って確かめる。利用制限が切れた場合、Mnemaiは30分後に自動でもう一度試すよ。キーは保存時にすぐ検証され、正しくないキーは接続済みとは見なされない。左上のモデルメニューはどのAIでも同じ作りで、接続済みのAIごとに、おすすめの上位3モデル(最新のフルサイズモデルと、軽量のminiやflash)と、件数つきの「すべてのモデル」リンクが表示される。「すべてのモデル」では、まず使えるモデルが並び、その下の線の先に「旧世代・内部用」がある。過去の世代(gpt-3.5、gpt-4、Claude 3)、日付つきのコピー、画像・音声・検索用のモデルが入っているよ。選択中のモデルは、上位3つに入っていなくてもメニューに表示される。キーと確認は、リストの下に折りたたまれている。「他のAIのメモリ」では、接続済みのタイルで、Mnemaiからプログラムに向かう線に沿って点が流れる。
- 内蔵モデル:「設定」→「AIとモデル」→「ローカルモデル」。

## プロキシとVPN

インターネットに出ていく通信(モデル、検索、モデルのダウンロード)はすべて、1つのプロキシを経由するよ。優先順位は次のとおり。まずMnemaiに設定したプロキシ(初回起動時、トレイメニューの「プロキシ…」、「設定」→「アプリ」→「VPNとプロキシ」)。なければシステムのプロキシ(Windows、macOSは「システム設定」→「ネットワーク」、Linuxは環境変数 https_proxy とGNOMEの設定)。それもなければ直接接続になる。HTTPとSOCKS5に対応していて、ユーザー名とパスワードも使える。パスワードはOSの安全な保管領域に保存される。VPNはキーでも使える。vless://、vmess://、trojan://、ss:// のリンク、または https:// のサブスクリプションを貼り付けると、MnemaiがMnemai専用のXrayを起動する(「キーをインポート」でクリップボードから読み込むか、「キーを手動で入力」を選ぶ)。すでに起動しているVPNクライアント経由でも使える。「テスト」を押すと、プロキシ経由でAnthropicまで実際に接続を試して、うまくいかない原因を教えてくれる。内蔵モデルはプロキシを経由しない。

## ウィンドウ、トレイ、インストール

初回起動時には、短い紹介が表示されます。1画面につき1つのポイントで、全部で6つのケースです(毎回説明し直さなくていい、ひとつのメモリをすべてのAIで共有、どのAIでもトークンを節約、会議→タスク、決定事項と期限を覚えている、シークレットは手元に残る)。そのあとでAIを選びます。トークンのケースでは、「トークンの節約」セクションの測定結果を紹介しています。契約書(153,000文字)に関する質問で、全文を渡すと入力は29,643トークン、Mnemaiを使うと6,159トークンです。「スキップ」を押すと、紹介はすぐに閉じます。

ウィンドウを閉じるとトレイに格納され、学習はそのまま続きます。初回だけ、Mnemaiは「トレイに格納するか、終了するか」を尋ね、その答えを記憶します。トレイメニューの「終了」を選ぶと、すべてが停止します。トレイメニューには「Mnemaiを開く」、「今すぐ学習」、「学習を一時停止」、「プロキシ…」、そして自動起動の項目があります(「Windowsと同時に起動」、macOSでは「macOSへのログイン時に開く」、Linuxでは「ログイン時に起動」)。2回目以降の起動で2つ目のウィンドウが開くことはなく、最初に起動したMnemaiのウィンドウが表示されます。Windowsでは、強制終了されたMnemaiのプロセスのアイコンが、起動時に自動でトレイから消されます。Linuxのデスクトップがトレイをサポートしていしていない場合は、ウィンドウを閉じるとアプリが終了します。

インストーラーは管理者権限なしで、Mnemaiを %LOCALAPPDATA%\Programs\Mnemai にインストールします。古いバージョンが見つかった場合は、そのプログラムファイルだけを削除し、フォルダ内のそれ以外のもの(たとえばプログラムの隣に作成したメモリ)はそのまま残ります。アンインストールしても、メモリは削除されません。アーカイブ形式のポータブル版もあります。インストーラーにはまだデジタル署名がないため、Windowsに「Windows によってPCが保護されました」と表示されます。「詳細情報」→「実行」をクリックしてください。まっさらなWindows 10では、MnemaiがウィンドウコンポーネントのMicrosoft WebView2を自動でインストールします(インターネット接続が必要なのは1回だけです)。macOSでは、.dmgイメージを開いて、Mnemaiを「アプリケーション」にドラッグします。Appleの署名がないため、初回は右クリックして「開く」を選んでください(または「システム設定」→「プライバシーとセキュリティ」→「このまま開く」)。Linuxでは、.AppImageファイル1つ(実行権限を付けて起動)か、フォルダ入りの.tar.gzアーカイブを使います。LinuxのウィンドウはQtで描画されます。開かない場合は、libxcb-cursor0とlibfuse2(AppImage用)のパッケージが必要です。

起動時にメモリフォルダが見つからない場合(移動された、名前が変わった、外付けドライブが接続されていないなど)、Mnemaiはその状況をそのまま伝え、新しい場所を指定する、もう一度確認する、新しいメモリを始める、のいずれかを提案します。最初の画面はシステムの言語で表示されます。サービスのエラーは、何が起きたか、何をすればいいかを言葉で説明します。エラーは会話に残り、途中で途切れた回答には印が付き、「停止」を押すとすぐに会話が解放されます。

## 歯車、テーマ、言語、実績

画面右上の歯車では、学習(一番上に状態を表示。メモリがオンのときは学習の一時停止スイッチも並び、オフのときは「メモリはオフです」という表示だけになります。モード、フィード)、テーマ、言語、実績(オフにできます)、「Mnemaiのしくみ」(ツアー)、「メモリのしくみ」(ガイド)、「Mnemaiリファレンス」を設定できます。オフにしたヒントもここから元に戻せます。対象は「新しい会話のチュートリアル」と「高額な会話のヒント」です。どのウィンドウの閉じるボタンも、「?」マークと同じ大きさの、細い×印が入った透明な円です。Escape キーでも閉じられます。学習なしの会話では歯車のドットがオレンジになり、それ以外では再び学習の状態に応じた色になります。歯車のドットは状態を表します。緑は学習中、黄色はメモリがオフまたは学習が一時停止中、グレーは明示的に伝えたことだけを学習する状態、または学習がオフの状態です。学習の状況は入力欄で確認できます。「Mnemaiが学習中 · メモリを N 分前に更新」と表示されます。会話を分析するモデルがない場合は、「Mnemaiは直接言われたことだけを記憶します」と表示され、明示的な内容(「覚えて …」、訂正、決定事項)だけが記録されます。

インターフェースの言語は9つあります。ロシア語、英語、中国語、スペイン語、ヒンディー語、ポルトガル語、フランス語、ドイツ語、日本語です。モデルは選んだ言語で応答します。会話とメモリは翻訳されません。

実績:全99個の報酬が5つのグループ(習得、メモリの成長、節約と習慣、プライバシー、レア)に分かれています。レアの多くは、獲得するまで非表示です。報酬で得られる経験値(10、25、50、100)に応じて、「ビギナー」から「永遠のメモリ」までレベルが上がります。

歯車には「Mnemaiリファレンス」もあります。これはアプリ内のリファレンスで、左にセクション、上に検索欄があり、見つかった語句はハイライトされます。設定は常に最初のセクション「AIとモデル」から開きます。起動時には、ロゴ、名前、キャッチコピー「Free Memory AI Interface」のスプラッシュ画面が1秒ほど表示されます。入力欄の歯車は小さく、右上の「?」の隣にあり、入力欄の設定を開きます。

## 複数のメモリ

「設定」の左側、各セクションの下に「メモリ」ブロックがあります。このパソコンにあるメモリがすべて並んでいて、開いているものにはチェックマークが付いています。別のメモリをクリックすると、そのメモリが開きます。「新しいメモリ」を押すと最初の画面に移りますが、今のメモリも一覧に残ります。メモリの ⋮ メニューには「名前を変更」と「削除」があります。「名前を変更」で変わるのは一覧に表示される名前だけで、ディスク上のフォルダ名はそのままです。削除は2回確認されます。2回目のウィンドウ「本当に削除しますか…?」には、なくなるもの(プロフィール、ファクト、会話、履歴)が一覧で表示されます。「削除」ボタンは10秒たつまで押せず、ボタンの下で赤いバーが減っていき、カウントダウンが進みます。フォルダはごみ箱に移されるので、そこから元に戻せます。開いているメモリは、Mnemai がまず閉じてから一覧の次のメモリに切り替えます。ほかにメモリがなければ最初の画面に戻ります。

## Telegram

「設定」→「学習」→「Telegram」。Mnemai は Telegram を API 経由で読み取るだけです。Mnemai 内の Telegram クライアントができるのはログインと読み取りだけで、それ以外の操作（送信、削除、既読にする、参加、リアクション）は、送信される前にアプリ側で拒否されます。ログインは Telegram Desktop と同じ流れです。my.telegram.org（API development tools）で取得した api_id と api_hash、電話番号、Telegram に届くコード、そしてクラウドパスワードを設定している場合はそのパスワードを入力します。その下に「読み取るチャット」があります。「チャットを追加」を押すと、自分の個人チャットとグループの一覧が検索付きで開くので、読み取りたいものにチェックを入れてください。チャットを1つも選んでいないあいだは、Mnemai は何も読み取りません。チャンネルとボットは選べません。選んだチャットでは、やり取り全体を読み取ります。自分の発言には「自分」、ほかの人の発言には相手の名前が付くので、Mnemai はあなた自身も、あなたの周りの人たちも把握できます。ログイン情報は OS の安全な保管領域に暗号化して保存され、チャットの一覧と学習した内容はメモリフォルダに保存されます。Mnemai 専用のサーバーはありません。「切断」を押すとログイン情報が消去されます。ただし Telegram 側では、そのセッションが「デバイス」に残ったままになるので、終了させるまでは残り続けます。

## 左下の「メモリ」カード

2つの行があり、それぞれが「証拠」を開いてくれる。「PC上のローカルメモリ」はメモリフォルダを開き、「アクセス設定」は「どのAIが何を見られるか」の表を開く。カードの歯車は保護設定につながっていて、隣にある緑色の「?」を押すと「メモリのしくみ」ガイドが開く。ガイドは全12章で、左に目次、右にシーン、説明、例（あなたが何を話して、メモリの中で何が起きるか）、そして「試してみる」ボタンが並ぶ。このボタンは、アプリの実際の場所に飛べる。章の内容は次のとおり：パソコン上のフォルダ、メモリフォルダのしくみ、事実の日付（それをいつ話したか）、会話からの学習、すぐ保存するか確認するか（しきい値は60%と80%）、訂正がルールになる、答える前に必要なものを選ぶ、AIの権限、シークレット、古い情報は聞き直す、巻き戻せる履歴、パソコン上のモデル。最後は「自分で確かめよう」で、フォルダ、誰が何を見られるか、外に出た情報を確認する。

試してみる（入力欄の下の「+」メニューと「メモリ」ページから）：
- 「はじめまして」— 7つの短い質問：あなたは誰か、どこに住んでいるか、今いちばん大事なこと、プロジェクト、周りの人たち、どう話しかけてほしいか、AIにやってはいけないこと。回答は普通の事実としてメモリに保存され、既存の内容を上書きすることはない。
- 「Mnemaiはあなたをどれくらい知っている？」— メモリにある10個の事実のクイズ。「合ってる」（ステータスに今日の日付が付く）、「もう違う」（今の状態を書くと、古い情報は事実のアーカイブに移る）、「間違い」（その事実はアーカイブに移る）。最後にスコアが出る。
- 「メモリありとなし」— つないであるAI（最大3つ）に1つ質問すると、それぞれが2回答える。メモリのない普通のチャットとして、そしてMnemai経由で。回答は並べて表示される。
- 「ローストモード」— ロースト形式のコンソーシアム。

どの結果も、カード画像にできる（「共有」）。コピー、「画像/Mnemai」への保存、リンク付きの投稿用テキストのコピーができる。画像に載るのは、送信前にウィンドウに表示されている内容だけ。

## Mnemaiにできないこと

- プログラムやスクリプトは実行しないよ。ファイルの操作は「アクション」だけで行って、対象はメモリフォルダと作業フォルダの中に限られる。どのアクションもジャーナルに記録されて、元に戻せるよ。
- システム標準の暗号化(EFS)が使えるのはWindowsだけ。Mnemaiのパスワードによる暗号化なら、どの環境でも使えるよ。
- 長いスキャンは、最初の40ページまでを認識するよ。
- インターネットがないと、クラウドモデルと検索は使えない。会話の途中でネットワークが切れたら、パソコン上のモデルが(ダウンロード済みなら)代わりに答えて、そのことを回答の上の行に表示するよ。
- メールやカレンダーは、アドレスとパスワード、またはリンクを教えてくれるまで読まないよ。
