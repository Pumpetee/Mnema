# Архитектура

[English version](ARCHITECTURE.md)

## Процессы

```
Mnema.exe (mnema/desktop.py)
 ├─ окно: pywebview на Microsoft WebView2 → http://127.0.0.1:<порт>/
 ├─ значок в трее (pystray): открыть, учиться сейчас, пауза, прокси, автозапуск, выход
 ├─ локальный API (mnema/api.py, поток): интерфейс и команды окна
 ├─ обучение (mnema/learn/engine.py, поток): читает разрешённые источники по таймеру
 └─ llama-server (vendor/llama, дочерний процесс, только пока работает модель на компьютере)

mnema-cli.exe / python -m mnema (mnema/cli.py)
 └─ mcp — MCP-сервер через stdio для Claude Code, Claude Desktop, Cursor
```

Одна копия на пользователя (именованный мьютекс): повторный запуск только показывает окно первой. Выход останавливает обучение, значок и окно; `GET /api/app/quit` делает то же для скриптов.

## Папка памяти

Обычный Markdown, читается и без Mnema. Константы раскладки и области доступа — в `mnema/vault.py`.

| Путь | Область | Что там |
|---|---|---|
| `00 Inbox/Inbox.md` | inbox | неразобранные факты |
| `10 Now.md` | — | сводка на сегодня, собирается сама |
| `20 Projects/<имя>/_Project.md` | projects | статус, цель, журнал проекта |
| `30 People/<имя>.md` | people | карточка человека |
| `60 Events/ГГГГ-ММ.md` | decisions | решения и смены статусов, новые сверху |
| `70 Memory/Profile.md`, `Rules.md`, `Thoughts.md` | profile, rules, notes | кто владелец, как с ним работать, его мысли |
| `70 Memory/Cards/<тема>.md` | cards | карточка темы; теги `#money`, `#health`, `#private` скрывают раздел |
| `70 Memory/Fact archive/` | — | заменённые факты, модели их не получают |
| `90 System/Journal/`, `90 System/Recipes/` | — | журнал человеческим языком, рецепты задач |
| `95 Saves/` | — | копия перед первой правкой за день |
| `.mnema/` | — | права ИИ, журнал со снимками, токены, состояние обучения, разговоры |

Факт — одна строка с датой. У статуса пометка `(статус ДД.ММ.ГГГГ)`; новый статус того же предмета заменяет старый на месте, старый уходит в архив фактов, смена — в ленту событий (`memory.remember`, `memory._put_fact`).

## Кто что видит

В `mnema/clients.py` на каждый ИИ один `Client`: какие области он читает, куда может писать, какие теги не видит никогда, включён ли. `memory.context_for(vault, client)` собирает контекст только по этим правилам, поэтому чат, MCP и расширение подчиняются одному правилу. Облачные модели в чате привязаны к своему клиенту (`chat/providers.py` → `PROVIDERS[...]["client"]`); модель на компьютере видит всё, потому что с компьютера ничего не уходит.

## Одно сообщение в чате

```
интерфейс (ui/js/19-chat.js) ──POST /api/chat/send──▶ chat/engine.send
  1. сообщение сохраняется; обучение на нём сразу идёт в фоне (learn/engine.learn_episodes)
  2. системная подсказка = правила поведения (agent/profile.py) + память, которую видит эта модель (context_for)
                           + как сейчас устроена Mnema (chat/selfknow.py) + разделы базы знаний, если вопрос о Mnema
  3. прикреплённые файлы: текст достаётся на компьютере (docs.py); сканы и картинки — файлом, где модель их читает
  4. интернет: только когда вопросу нужны свежие внешние данные (web.should_search), страницы читаются на компьютере
  5. облачная модель: секреты заменяются метками (outgoing.py), запрос пишется в журнал; модель на компьютере — как есть
  6. ответ идёт потоком; метки возвращаются; блок ```ask становится кнопками; словарь терминов отрезается
интерфейс опрашивает /api/chat/poll и рисует
```

Консорциум (`chat/consortium.py`) ведёт 2–4 модели по очереди: формат (совет, дебаты, мозговой штурм, красная команда), роли, кто подводит итог, длина реплик; каждый участник получает память по своим правам.

## Обучение

```
источники (learn/sources.py, learn/sources_life.py)  → Episode(источник, ссылка, время, текст)
  только включённые и разрешённые: settings.allowed() — "только Mnema" закрывает всё за её пределами
разбор (learn/brains.py): явные сигналы, Claude Code, ключ API или модель на компьютере → факты-кандидаты
журнал выученного (learn/ledger.py): повторы повышают уверенность; хранится день, когда это сказано (said_at)
решение (learn/engine.decide_why): записать / спросить / ждать / пропустить — с причиной в ленте
запись: memory.remember(..., said=день) → журнал, сводка и оглавление пересобираются
```

Очереди "ждёт тебя" нет. Из разговора в Mnema личное или противоречие уточняется одним вопросом прямо под этим разговором (`chat["learn_ask"]`, ответ через `/api/learn/review`); из других мест Mnema решает сама: личное — в скрытую часть, новое заменяет старое (старое уходит в архив фактов), слабая догадка ждёт повтора. Откат выученной записи — окончательное "нет".

## Что уходит с компьютера

`outgoing.py` перед любым облачным запросом меняет номера карт (с проверкой Луна), пароли, ключи API, токены, телефоны, паспорт и СНИЛС на метки и возвращает настоящие значения в ответ. Каждый облачный запрос — строка в `.mnema/outgoing.jsonl`: когда, кому, зачем, сколько памяти из доступной, что скрыто (только количество).

## Интерфейс

`mnema/ui/index.html` — каркас страницы; `css/app.css` — стили; `js/NN-*.js` — обычные скрипты, грузятся по номерам и делят одну глобальную область (`01-core.js` с общими функциями первым, `29-navigation.js` и `30-boot.js` последними: они выполняются при загрузке и вызывают всё остальное). Тексты написаны по-русски; `ui/i18n/<язык>.json` — ещё девять языков, перевод накладывается на страницу.

## Тесты

`tests/` — модульные тесты без сети и настоящих моделей (провайдеры, поиск и разбор подменены). `tools/qa/` — прогон настоящего интерфейса по кнопкам на временной памяти. GitHub Actions на каждый push запускают проверку стиля, модульные тесты и проверку скриптов интерфейса (`.github/workflows/tests.yml`).
